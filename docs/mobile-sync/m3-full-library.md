# 完整文库、会话与远程任务

本轮把 M3 的富文本、笔记与引用导出、Zotero 增量、同步会话和受控远程解析/索引接入实际页面与账号事务。最新真实浏览器／桌面服务链仍未验收，原因与已通过的检查见 [集成检查点](m3-integration-checkpoint.md)。四类实机继续按用户要求暂缓，M3 整体门槛尚未关闭。

| 操作 | 入口与结果 | 保留边界 |
| --- | --- | --- |
| 结构笔记 | 移动端新建空白笔记选择结构笔记；格式、任务、公式、本地图片、表格及预览 | 已有 Markdown 不自动转换；保存完整 TipTap AST、元数据和图片；非法草稿保留但不可保存 |
| 桌面已保存笔记 | 笔记工作区的导出按钮，选择保存 JSON v2 文件 | 从已保存真值只读捕获；保存框返回后再核验来源；图片先校验 CRC／摘要并实际解码，不能保真的整条列明跳过原因 |
| 笔记、批注与引用 | 阅读器或账号页的导出入口；按文献、标签、关键词选择，核对预览后下载或系统分享 | JSON v2 完整保留富文本与图片摘要；纯 Markdown 范围仍输出 v1；阅读汇总不是全账号备份 |
| 文库文件交换 | 导入与导出面板读取 v1/v2；包含富文本时输出 v2 | 包内来源键只用于重绑；新建目标 ID；未知或未导入引用明确未解析，不能按原 UUID 连接另一账号 |
| Zotero 增量接入 | 账号页填写个人库／群组库 ID，选择公开读取或本设备专用密钥；读取、比较后明确采用 | 只对官方 API GET；不写 Zotero、不下载附件；来源删除仅提示；映射和游标留在此设备，题录正常同步 |
| 同步会话与模板 | AI 助手或账号页打开“同步会话与模板”；明确保存后进入同步队列 | 会话包括共同原文、每轮问题、公开模型引用、回答及真实终态；密钥和模型设置保留在本设备 |
| 多轮继续 | 打开已保存会话，明确使用其保存的原文继续；发送前查看范围 | 每次发送共同原文和此前完成的问答；不把取消或失败回答作为已完成前文；费用未知 |
| 远程解析与索引 | 阅读器解析面板或账号页选择同账号电脑、配置和已同步 PDF 版本 | 电脑须明确开启并保持运行；所选 PDF 或解析文字会送往电脑配置的外部服务，可能付费；不自动处理整库 |

同步服务通过 `rich-notes-v1`、`ai-conversations-v1` 协商新内容。旧客户端继续推进游标，但看不到不支持的正文，也不能删除、覆盖或压平这些记录。升级客户端保留待同步操作，并重新拉取此前隐藏的数据。恢复到不支持能力的服务时，已保存内容仍保留，发送会被阻止。

结构笔记每条最多 1 MiB；图片仅 PNG/JPEG/WebP，每张最多 512 KiB，单张 4M 像素、合计 8M 像素。图片先校验格式、字节、尺寸、SHA-256，再实际解码显示；远程图片、HTML 粘贴、拖入和未知节点不会被静默转换。历史引用与坐标保留未验证状态，资源限制不会被当作已无损导入。

同步会话每账号最多 50 个、模板 100 个；单会话最多 24 轮、1 MiB。达到轮数上限时先阻止继续请求；超限更新整次拒绝，保留旧内容。冲突或容量不足时，可以明确只把本轮另存为新会话，不带此前问答。保存和删除在实际存储事务中同时复查完整数据、revision、保留冲突与待决解决操作，不凭页面里旧的“无冲突”状态覆盖内容。

Zotero 每轮最多 500 个变更键、累计 4 MiB、24 次请求、30 秒；分页和删除列表须属于同一来源版本。限流、版本重读和所有等待计入总预算，超限不部分采用。采用时，在同一账号事务中复查旧游标与预览签名，再一并保存题录、来源映射、outbox 与新游标。重新全量读取只重置此来源的本机游标，不自动联网、删除题录或清空映射。密钥按同步服务、账号及 Zotero 来源隔离；浏览器只保留当前应用内存密钥，原生端使用系统安全存储。

远程服务默认关闭，管理员显式设置 `PAPERQUAY_REMOTE_TASKS_ENABLED=1` 后才公开能力。数据库须先应用全部迁移及最小运行角色授权；当前新增迁移为 005–008，不能修改已经应用的迁移校验和。开启功能不等于生产部署已验收。

服务端每账号最多 1 个执行中任务、16 个排队任务、200 个保留任务、2,000 条幂等回执；产物每份最多 16 MiB、合计 64 MiB。移动端先把创建请求 ID 与完整载荷落盘，再提交；结果不明时只允许明确重试同一请求。任务和原文版本持久保存在账号服务，不依赖手机后台常驻。删除已结束任务释放服务端产物，幂等回执仍保留，旧请求不会重新执行；满额只拒绝，不自动驱逐记录。

桌面每次启动后都须重新明确开启远程执行。配置同意令牌在设置变更时失效；公开配置只含功能、模型与摘要，端点、密钥及私有凭据代次不会发布。账号、文库、配置或凭据变化会中止执行并撤回可用状态。任务读取当前已选映射并固定文件句柄，每次复用本机结果也重新核对 PDF 字节、hash 与大小。

电脑重登录产生新设备会话时，用户可选择同公开配置的新会话明确恢复。服务端保留最近确认持有执行记录的设备；新会话须先核验本机旧记录并持久接管，再以有效租约确认，之后才允许外部执行。误选没有旧记录的电脑不会抹掉原来源。首次从未被领取的任务可首次准备；已经领取而丢失记录的任务拒绝重新收费提交。MinerU 已知 batch 仅查询和下载，不确定的提交不重发；向量已收到批次复用，结果不明的付费批次不自动重试。

桌面私有日志上限 64 MiB／200 条，远程解析专属缓存上限 256 MiB；只拒绝超额，不删除用户文件。停用后可以明确清理本机已完成记录；未知或未完成阶段继续保留。解析产物核验后进入移动端独立缓存，索引导出为带版本、来源摘要、模型、维度和内容 hash 的文件；索引导出不代表 M4 跨文献检索已经接通。

桌面旧 Reader／旧 SQLite 的双向回写、历史坐标版本推断、真实外部账号与实际账单、手机后台和原生生命周期、公网连通性、生产容量、备份恢复及签名升级仍按各自阶段门槛验收。
