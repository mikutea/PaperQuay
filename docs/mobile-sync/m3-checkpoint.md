# M3 首批开发检查点 · 2026-10-26

本轮完成文库文件交换的首批实现，并补齐 M2 扫描 PDF 在无 WASM 环境中的离线回退。M3 仍在开发中：此结果不关闭全文来源、中继、私有云、外部库映射、解析视图、完整富文本和远程任务的阶段门槛。实机继续按用户要求暂缓。

同日后续的 BibTeX / RIS、DOI 查询见 [M3 书目检查点](m3-bibliography-checkpoint.md)，可选私有 PDF 副本及最新回归见 [M3 私有云检查点](m3-cloud-checkpoint.md)；下表保留首批开发时的验证结果。

## 已实现

- 文库和笔记页提供“导入与导出”面板，复用现有悬浮导航与可访问面板。JSON/Markdown 文件先预览，再保存。
- 重复项默认跳过；明确选中后生成新 ID 和新副本。仅同名不会自动合并。关联笔记明确显示目标；缺失或多义关联会阻止保存。
- 事务内重新计算预览，比较相关现有记录、revision、待同步内容与选择。一次提交所有新记录和队列，容量不足、账号/设备/绑定变化、存储失败均不产生部分导入。
- 文库 JSON 与单篇 Markdown 真实下载；JSON 只导出文档定义的题录、分类和 Markdown 内容，不打包同步快照或凭据。格式与限制见 [文件交换说明](library-transfer.md)。
- 原生系统分享组件已接入并更新 Android/iOS 工程。文件准备后复核账号；用户决定保存位置或接收应用。
- 扫描 PDF 使用匹配当前 PDF.js 的 JPEG2000/JBIG2 JS 回退。无 WebAssembly、禁用 WASM 或实例化失败时，在已加载应用中完全离线解码。

完整移动端回归后只调整面板错误位置、选择控件标签、预览布局和超限提示，以及显式固定测试用 canvas 依赖；这些调整后重做 TypeScript、生产构建、相关 29 项回归与最终 9 组浏览器链路，没有把旧构建截图作为最终结果。

浏览器为 Chrome 155.0.8059.80。Browser 插件未提供，使用已安装 Playwright；入口为 `http://127.0.0.1:4317` 的生产构建预览。覆盖 390×844、320×640、820×1180、1280×900、200% 根字号、深色、键盘焦点循环与 Escape。页面身份、非空内容、框架错误层、console、截图和交互检查全部通过。

实际流程为：选择 JSON → 查看三条预览 → 连续点击两次仍只导入一次 → 重导默认全跳过 → 明确另存文献与笔记副本 → 检查独立关联 → 拒绝未知账号字段和缺失关联 → 对 100 条导入注入存储失败并验证无部分写入、提示可见 → 断网导入 Markdown → 读回真实下载字节 → 恢复联网 → 第二个独立客户端读取相同文献和笔记。没有页面错误、console 错误或意外确认框。

扫描 PDF 使用原创 CC0 小型 JPX、JBIG2/MMR、CCITT 两页夹具。浏览器回归覆盖四种 WASM 条件下的首开、后续页和新 Worker 重开；实际原生 WebView、完整色彩保真、大文件与全部编码变体仍待证明。

任务外部 `qa/m3/20261026/` 保存脚本、测试日志、JSON 结果、真实下载文件和截图；`pdf-resources/` 保留原失败基线及修复结果。全部为隔离合成数据，不保存密码、token、认证状态或 HAR。文档中的规划页面已同步到 M3 首批状态。
