# M3 私有云 PDF 检查点 · 2026-10-26

本轮接通主动上传的私有 PDF 副本：同账号另一客户端同步附件版本后，可以下载、核验并阅读该文件。管理员开关默认关闭，用户必须逐份上传。M3 的全文来源调度、在线电脑取文件、中继、外部库持续映射、解析与完整富文本继续开发；四类实机按用户要求暂缓。

## 已实现

- 阅读器新增「私有云 PDF」，仅对已同步的附件版本上传当前已验证字节；从文件面板或手机更多菜单进入。没有自动整库上传。
- 下载绑定当前账号、设备、文献和附件版本；在完整长度、SHA-256 和 PDF 解析通过后写入本机缓存。账号切换、会话失效、删除文献、版本变化或关闭面板会取消或丢弃旧结果。
- 账号页集中管理云副本与额度。文献或版本删除后，保留的副本标为不可读取，仍可明确删除。删除云副本保留文库、笔记、批注与本机缓存。
- PostgreSQL bytea 原子保存内容和独立额度。默认 1 GiB/账号、最多 512 份、64 MiB/文件；账号复合外键、FORCE RLS、数据库长度/哈希约束及事务内授权复验约束写入。
- 删除推进内部 generation。已准入但尚未提交的旧上传，不能在删除后重新创建副本；相同字节的正常重试不重复占额度。
- 全进程最多 2 个二进制传输、同账号最多 1 个，45 秒截止；下载以 64 KiB 分块响应，槽位持续到响应完成/断连及数据库动作结束。元数据查询和删除不占这些槽位。

操作、协议、保存边界与部署限制见 [私有云 PDF](private-cloud-pdf.md) 和 [服务端说明](../../server/README.md#可选私有-pdf-副本)。

### 浏览器与实际链路

Chrome 155.0.8059.80，生产预览入口 `http://127.0.0.1:4317`。Browser 插件未提供，使用已安装 Playwright。覆盖 390×844、320×640、820×1180、1280×900、200% 根字号、深色、减少动态效果、焦点约束与 Escape 恢复。最终页面与 console 错误均为 0，截图未见横向溢出、遮挡或框架错误层。

真实链路：导入本次唯一合成文献和关联笔记 → 打开本机 PDF，确认没有自动上传 → 显式上传 → 重启隔离 API，核对副本与额度仍在 → 独立浏览器先拒绝受控损坏响应，确认未写缓存 → 下载真实云副本，验证 hash、长度和非空 canvas → 关闭 Reader，断网从缓存重开 → 删除云副本，核对文库、笔记和原缓存仍在 → 重新上传并仅删除本次合成文献 → 账号列表仍可清理不可读取副本，额度归零。

使用自生成 JPX PDF，9978 bytes、2 页，SHA-256 为 `987e8101807883c6650cea72ca47d22ece4cace67aa9a386461b38496fc7605b`。仅损坏内容场景使用受控响应；实际上传、服务重启后下载、额度和删除均经过真实 API。

### Electron 验证边界

Electron 42.11.9 使用项目实际 `main.cjs`、preload 和可信 IPC；`appData`、`userData` 均落在任务专用目录。`library_list_papers` 从该隔离桌面 SQLite 返回空库。QA 入口使用实际移动 Reader/云面板/缓存模块，控制器适配器将合成数据与阅读位置连接至真实身份与同步服务。

四组实际操作包括：隔离桥接与空库读取、本机 PDF 验证和显式上传、云下载渲染及缓存/阅读位置落盘、窄屏确认删除云副本后保留本机 PDF 并通过 Escape 返回阅读。隐藏窗口截图额外等待合成帧，不把 DOM 已更新等同于截图已更新。

此验证不代表旧桌面业务已接入双向同步，也不代表 Android/iOS 的安装、后台恢复或触控验收。共享盘启动 Electron 曾发生 GPU 子进程启动错误；将已安装的同一 Electron 发行目录复制至任务专用本机目录并核对 EXE hash 后完成验证，没有安装或替换用户应用。
