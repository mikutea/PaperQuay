# M4 公开题录补全与审批来源

2026-10-31，本轮基线为模型 Agent 检查点 a1c74ff。代码接入不代表 M3/M4 真实服务或设备验收完成；原服务和 preview 启动拒绝仍保留，不通过其他端口、工具或路径绕过。

实际入口：账号页 → 文库 Agent → 选择文献 → 公开题录补全。可重开已保存会话，打开与刷新不查询来源。本机规则、模型 Agent、公开题录分别保留明确的请求与审批步骤。

一次至多明确选择16篇、题录快照1MiB；每份会话最多32次查询、8MiB，只在当前账号/此设备保存。逐篇选择 DOI 精确查询或标题相关候选，预览确切检索词与固定 Crossref API 地址后再查询一次。标题使用官方仍支持的 query.bibliographic，最多5个候选，无默认选中，无自动分页、其他来源替换、日期过滤或重试。来源排序不能证明同一文献，用户需核对作者、年份、期刊和 DOI。

HTTP 为匿名 GET，凭据省略、禁止重定向、不携带账号令牌、模型密钥或本机摘要/PDF。响应1MiB、最多4096块、请求10秒（独立单调时钟与中止定时器），严格 UTF-8、JSON 深度/重复键、来源 DOI 和 schema 校验。跨实例保守1100ms间隔；429/503的 Retry-After 冷却有界保存，按账号保留，替换会话不会清除冷却。请求前预留完整验证响应的保存容量，超限在 HTTP 前停止。

查询意图先在账号事务保存，获得确认后才发请求。未知请求重开不补发，可明确标记停止本机等待；这不证明远端没有处理。收到结果后本机保存失败时保留候选，可备份或只重试保存，不能在恢复过程中再次查询。来源后来变化时仍可保存已收诊断，但新查询、计划送审和首次应用会重新核验账号与题录版本。账号退休、会话替换与过期回调不能写入新账号。

候选必须手动确认；可按字段勾选采用。题录补全复用桌面 metadataUpdateForPaper 的非空字段与作者比较语义；来源缺失不会清空本机内容。Crossref subjects 只是候选关键词，默认不替换已有关键词；明确勾选后才采用。当前移动格式不提供 URL 改写。生成的是实际前后差异，随后仍需文库 Agent 的逐项勾选、应用预览和确认。

候选、字段选择、请求及来源版本绑定确定性的计划标识和摘要。计划与一次送审标记原子保存；保存回执丢失时核对原标记，不覆盖更晚计划、不重建已应用计划。题录、待同步操作与审批回执仍一起提交；任一来源版本变化时整批停止，跨端是否成功以真实同步回执为准。

模型与 Crossref 的来源摘要现随计划和回执保存。模型记录实际公开配置、请求/结果摘要、明确参与的题录版本及批准片段/解析包/页码集合摘要；不把原文重复复制到每条回执。Crossref 保留确切查询 URL、时间、返回 DOI、响应/原记录/映射题录摘要、年份来源与缺项/转换警告。换模型会话或题录补全会话后已保存回执仍有依据。摘要不是第三方签名或全文备份；完整请求、已批准文字与候选分别在对应工作区导出。本机审批历史最多256条，完整候选只保留每篇最近一次成功结果，较早查询保留请求及响应摘要。
