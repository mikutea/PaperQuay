# M3 版本绑定的解析阅读检查点 · 2026-10-28

解析阅读已接入移动 PDF 阅读器，支持公式、表格、图片、续页与本机离线缓存；桌面新增带来源证据的解析包导出。移动端使用合成包验证，实际 Electron 解析→导出→移动导入闭环尚未通过。四类实机按用户要求继续暂缓，READ-02 仅有局部证据，M3 尚未整体完成。

## 已实现范围

- 桌面将实际上传的 PDF 字节与独立解析结果目录、ZIP 产物摘要绑定。主进程用系统安全存储保护的密钥生成 HMAC 证据；缺少证据的旧缓存不能补标可信。安全存储不可用时保留解析结果，仅禁用验证导出。
- 从明确关联的附件导出闭合 JSON，保存框返回后再次检查账号、库映射、版本、文件与来源。以真实 PDF.js 得到页数；输出不包含本机资源地址、令牌、下载 URL 或原始 OCR 对象。
- 结构转换保留文本、LaTeX、表格分区、rowSpan/colSpan、标题、脚注及位图。无法完整表达的嵌入对象、多个/嵌套表格等明确拒绝，避免静默丢失内容。Markdown/HTML 的本机资源目标被拒绝；普通正文路径文字不被误删。
- 移动端打开同一 PDF 后主动导入，比较文献 ID、附件版本、SHA-256、字节数和实际页数。KaTeX 禁止不可信扩展，Markdown 不执行 HTML 或加载远程图片，位图先核验再实际解码。
- 续块使用同类型来源内容，同时保留当前块 ID 和当前页跳转目标。当前只按页返回原文；不推断 MinerU bbox、PDF CropBox 或旋转坐标的对应关系。
- Web 使用独立 IndexedDB，原生使用独立 SQLite。正文和目录原子保存；目录避免容量检查整批读取正文。每账号 64 MiB/32 份，满额拒绝。失败保留旧包，损坏缓存可单篇或全账号清理，PDF、笔记、文库和原导出文件保留。

解析包通过文件交接，不自动上传或同步。另一设备需要打开相同 PDF 并再次选择文件。详细格式、限额和操作见 [版本绑定的解析包](parsed-documents.md)。
