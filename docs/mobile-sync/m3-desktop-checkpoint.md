## 本轮实现

- 桌面设置新增「账号与在线文件」：保存服务设置、系统浏览器 PKCE 登录、选择 PDF、发布或关联已有版本、开启/停止提供、取消传输、重试和解除关联。
- 主进程验证 OIDC 身份并在内存保管令牌；重启要求重新登录，文件提供默认关闭。身份服务地址、回环回调、state/nonce、签名、刷新主体及取消都有边界检查。
- 复用共享同步核心，为选中文献建立稳定 UUID、映射和持久 outbox。题录确认后再发布附件版本；未知提交结果使用同一操作 ID 重试。旧桌面数据不接受远端快照回写。
- 只读取明确关联且已导入的附件，使用现有路径授权、固定文件句柄及完整哈希/长度校验；远端无法指定任意路径。文库替换、账号变化或源文件变化都会阻止旧映射继续供给。
- 服务新增默认关闭的 `desktopPdfTransfer` 能力：同账号不同会话、单次请求、30 秒内租约、持续权限检查、有界流与背压、取消/撤销清理、并发槽位及临时流量预算。
- 移动端新增「在线电脑」来源，最多等待 15 秒；不存在可用提供方时继续私有云。明确的认证或目标失效停止整次读取。初次打开仍只读缓存。

操作及限制见 [在线电脑取文件](desktop-pdf.md)；来源与取消语义见 [按版本打开全文](pdf-sources.md)。

### 真实链路与边界

使用真实仓库 Electron main/preload/IPC、唯一隔离 profile、原生 SQLite 与附件读取，连接隔离 Keycloak、PostgreSQL 和 API；移动端使用生产构建及真实 PDF.js/IndexedDB。系统文件选择器仅返回本次合成 PDF，系统浏览器启动入口导向受控 Chrome context；未替换授权交换、回环回调、业务 HTTP、文件流、解析或缓存。

合成 JPX PDF 为 9978 bytes、2 页，SHA-256 为 `987e8101807883c6650cea72ca47d22ece4cace67aa9a386461b38496fc7605b`。桌面读出、实际 HTTP 响应与移动缓存均匹配该值，页面 canvas 非空。初次缓存缺失不发起电脑或云内容请求；主动取回优先命中电脑，随后缓存命中不再请求其他文件来源。关闭电脑供给后，已缓存文件可断网重开。

扩展验收还确认：

- 另一账号查询版本或创建该版本请求均为 404。
- 桌面停用后，新的独立客户端回退到主动上传的真实云副本，并核验、解析、缓存成功。
- 320/390/820/1280 宽度、200% 根字号、减少动态效果、面板滚动及 Escape 均可用。
- 关闭并重启同一 Electron profile 后，配置和版本关联保留；重新登录得到新会话，提供开关仍关闭。
- 修改本次原生附件的真实字节后，桌面标记文件变化，拒绝作为原版本发送。恢复夹具，再显式解除并关联已有版本成功；原文件和账号题录保留。
- 另一会话撤销当前桌面会话后，桌面在本次采样约 1.64 秒内停止提供并退出绑定；原文件保留。此数值是本机采样，不是公网服务等级保证。

### 协议故障与修复

真实 socket 覆盖取消、双向断线、撤销、固定截止、坏哈希、最终授权前保留末块，以及暂停读取 64 MiB 时的背压：服务端响应尚未完成、上游尚未整份读入、应用缓冲有界，第二请求被拒绝，断开后槽位可复用。Windows 客户端写入缓冲可能接纳完整请求，未将其误作服务端完整接收证据。提供方切换总数最多 4 次，换会话也不能绕过单次请求限制。

真实联调发现桌面能力校验误拒绝服务额外预算字段，已改为验证所需字段并投影已知合同。独立审查发现畸形回环请求路径可能抛出异常，以及同一时刻重复登录可能发起两次注册；分别以真实原始 HTTP 路径和并发登录探针复现并修复。取消启动、错误 state 后继续正常登录、单次注册、过期/变更主体、迟到结果和文件 I/O 释放均有回归。

验收脚本还修正了状态选择器、渲染完成后面板自动关闭、错误状态字段、缺省测试账号、响应式重挂载时序及空 DELETE 请求的 Content-Type。没有为这些脚本问题修改产品逻辑。原失败记录、修正原因和最终完整重跑保留。
