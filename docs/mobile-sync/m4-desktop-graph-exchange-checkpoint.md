## 使用流程

在桌面设置的账号区域打开“图谱关系交换”。登录只读取能力和本机私有状态，不自动拉取、发布、接收或重试关系。用户点击检查后读取固定的账号变更和冲突接口，展示本地差异、账号新版本、待处理原请求和冲突两版本；默认不勾选任何行。

发布和接收分别确认。发布只发送选中的关系，删除及恢复另有明确确认；接收只把选中的已检查账号版本保存为这个服务、账号和文库的私有图谱，不覆盖原本地图谱 JSON。两端必须具有当前唯一映射，不猜标题、路径、相同 UUID 或文件交换别名；不创建、恢复或替换材料。缺少或损坏的本地图谱文件不会被解释为删除全部关系。

原始来源、自定义/已批准 AI 类型、创建和修改时间、完整说明与未知分数保留。未知分数不补成 0 或 0.7，已知 epoch 0 时间也保留。未知字段、无损转换失败和缺少映射的行明确列出，可查看原始本机字段；不会截断说明后再发布。

## 本机状态与恢复

原有关系文件始终是只读的发布来源。账号私有文件保存完整游标、服务头、已接收副本、稳定来源链接、outbox、冲突与原解决请求；按服务、账号和文库分开，当前设备会话另作运行上下文校验。

发送前保存原 entityId、opId、完整正文和版本基线；网络结果不确定或回执丢失时继续同一请求，不生成替代 ID。重开不自动联网。“继续原请求”只处理可继续的请求，明确拒绝和冲突保留供核对；服务拒绝删除后仍显示已接收关系，不把本机删除意图当作服务器成功。已接收版本落后于最新已知服务器版本时，不能直接编辑或删除，需先核对新版本。

写入采用现有账号写锁与 NativeFS 原子替换，并在前后比对实际字节。NativeFS 没有写入 CAS，因此不宣称跨进程内核 CAS 或多文件事务。外部改动或保存结果未确认时保留候选，可导出或仅重试保存，不重新联网。退出、能力校验失败和关闭期间，写锁保留到旧动作实际结束；账号切换后投影与迟到界面结果失效。

“导出备份”通过原生保存窗口写出私有图谱、原请求、冲突及未确认候选，最多两份各 16 MiB 状态加固定封装。它不包含原本地图谱 JSON、无法转换的本机原行、PDF 或笔记正文；这些原文件未被交换修改，仍需使用原有文库备份。取消窗口不会写文件，窗口打开期间账号或文库变化会阻止旧保存。

## 图谱与可见性

已接收的账号关系在当前唯一映射下进入实际知识图谱，并显示账号来源。已明确链接且本机未再改变的原关系可抑制重复显示，原始 JSON 仍保留。若原 ID 与账号显示 ID 恰好相同，本机行优先，不把两层都隐藏。账号、材料绑定或私有投影变化会刷新视图，避免旧账号关系残留。

图谱 JSON 仍只导出当前可见图，不是完整关系备份。文库交换 JSON v1/v2 仍不包含关系。桌面参考文献缓存、向量边以及未建立可信映射的笔记端点没有借此自动同步。
