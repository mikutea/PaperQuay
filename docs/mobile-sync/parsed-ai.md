# 用解析文本询问 AI

在 PDF 阅读器打开「解析」，导入与当前 PDF 版本匹配的解析包后，可选择「用本页解析文本提问」或「用解析包文本提问」。先在 AI 助手查看实际页码、字数与将发送的文字，再选择任务并点击发送。

## 发送内容

- 本页指解析面板中当前选定的页，不以 PDF 此刻的滚动位置替代。解析包范围包含实际有可发送文字的页，空页不会凑成全文。
- 保留文字、LaTeX 公式、结构化表格的行组、表头、跨行跨列、题注与脚注。续块沿用同类型来源内容，并保留当前块所属页。
- 图片只提供已有文字、题注和脚注，不发送图片像素、base64、资源目标或本机文件位置。链接保留可见文字，移除目标；公式中的资源命令、不能完整转换的 HTML 等会明确拒绝。
- 上下文最多 192 KiB UTF-8；超限拒绝，不静默截断。可改选有用的单页后重试。

范围始终标为解析文本。解析包可能存在 OCR 或结构识别错误，即使涉及每一页，也不声称已阅读全文。模型返回的页码只有属于本次实际提供的有文字页面，才显示回跳按钮；只按页定位，不生成解析坐标。

## 版本、取消与保存

每次准备都会重新验证整个解析包、图片完整性、内容摘要，以及文献、附件版本、PDF SHA-256、字节数和实际页数。准备期间取消、切换账号或版本，会废弃迟到的结果。进入助手不会自动请求模型。

替换或清理解析包会使对应的旧解析上下文与请求失效。取消若发生在本机缓存已提交之后，页面会撤下旧内容并提供「重新载入解析缓存」，按实际存储结果恢复；不会把已经提交的变更当作尚未保存。普通 PDF 提取文本的上下文独立保留。

「保存为文献笔记」记录 PDF 版本、解析包摘要、文字来源说明、页码和模型；排队保存也在事务内核对实时来源与实际文库版本。笔记正常跨端同步；解析缓存、模型配置和密钥不随这条笔记同步。解析包摘要标识内容变化，不代表服务端认证或来源签名。

## 当前验收边界

本机验证使用真实移动 OIDC、API、PostgreSQL、PDF.js、IndexedDB 和本机 HTTP 合成模型。导入文件由转换器生成，仍不是实际 Electron 导出产物。真实模型提供商、跨域/网络限制、手机和平板、原生生命周期与系统安全存储仍待验收。

这一步接通已有解析文本与 AI；[本机独立问答记录与问题模板](ai-history.md)现已接入；跨端会话和多轮恢复仍待后续。远程解析、向量索引、完整富文本和桌面真实导出到移动端的闭环继续按计划推进。结果见 [本轮检查点](m3-parsed-ai-checkpoint.md)，解析包本身的来源与格式见 [解析包](parsed-documents.md)。
