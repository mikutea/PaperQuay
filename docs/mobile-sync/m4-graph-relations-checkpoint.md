## 使用与数据

账号页打开“知识图谱”。连接支持 graph-relations-v1 的服务并重新登录后，首次开启能力会补取此前隐藏的关系，保留已有文库、outbox 与冲突。只读检查服务能力不会启用内容格式或重置游标。旧服务和旧客户端仍可处理各自支持的内容，不能读写此关系类型。

可从已同步文献/笔记创建关系、修改名称/说明，或明确确认删除。原始两端、来源类型及创建时间不因编辑而改变。AI 建议只有已保存关系的来源标记；未知置信度保留 null，已有分数不是校准后的正确概率，此页面不调用模型。修改时间与同步服务的提交时间分别保留。

保存时重新读取当前账号事务，核对两端材料和完整原关系状态。并发修改、来源变化、删除和账号变化拒绝覆盖。草稿在失败、来源节点移除后仍保留原始来源，不自动改连其他节点。关闭、换节点和筛选前保护未保存草稿。

只有两端在当前范围可见的关系进入图谱。至少一端已删除/未在本副本的关系仍保留，可在“两端材料不可用的关系”核对并单独删除，不恢复任何材料。待同步/冲突关系不直接覆盖。每账号最多512条活动关系、2MiB活动内容；名称80字、说明4096字、单条16KiB，超限拒绝而不截断。历史副本、冲突与回执另外受原有账号保留额度限制。

文库 JSON v1/v2 不含关系，界面明确说明遗漏。图谱 JSON 仅导出当前可见范围及证据，不能替代完整账号备份，缺少端点的关系不混入可见图。
