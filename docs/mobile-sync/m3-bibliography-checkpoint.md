# M3 书目交换与 DOI 检查点 · 2026-10-26

本轮在已有 JSON / Markdown 原子导入基础上，接通 BibTeX / RIS 文件交换与 Crossref DOI 题录预览。所有导入继续先审阅、再创建记录，不覆盖现有文献。M3 的全文来源、中继、私有云、外部库持续映射、解析视图和完整富文本仍未完成；四类实机继续暂缓。

## 已实现

- `.bib` / `.bibtex` / `.ris` 文件导入，保留标题、作者、年份、DOI、出版来源、关键词和摘要。字段转换提示可展开查看，逐篇题录可核对。格式错误、无效 UTF-8、字段超限或畸形批次均不产生部分写入。
- 全部文献或单篇的 BibTeX / RIS 导出，使用通用条目类型并明确提示字段损失。作者文字受到保护；换行、LaTeX 特殊字符和条目边界不会注入额外记录。具体映射与限制见 [文件交换说明](library-transfer.md)。
- 无 DOI 的相同题录不再因个人标签、收藏或阅读状态不同而产生默认重复副本。JSON 中明确选中的副本仍保留各自分类与笔记关联；多重匹配继续阻止不确定的笔记关联，预览签名仍检查分类变化。
- 显式 DOI 查询只向固定 Crossref 接口发送规范化 DOI，不发送账号凭据或文库内容。返回 DOI、字段长度、响应体积和日期来源通过核对后生成预览，用户确认后才入库。
- 查询可取消，关闭或账号变化会丢弃过期结果。取消 A 后启动 B，A 的迟到结果和收尾不能覆盖 B 或解除 B 的忙碌状态。超时、429、不匹配和网络失败保留明确的无写入错误状态。
- 原生文件分享保留 `.bib` / `.ris` 扩展名；Web 使用真实下载。补齐移动网页图标，并在手机上折叠冗长转换详情，保留可见的变化数量和导入操作。

本轮使用受控 Crossref 浏览器响应检验 UI 与网络边界；真实 Crossref 探测返回过 429，尚无真实服务成功的验收证据。BibTeX 有独立 Citation.js 解析验证，不能据此宣称真实 Zotero 客户端的全字段导入已经通过。

任务外部 `qa/m3/20261026/bibliography/` 保存验证脚本、日志、实际下载、JSON 结果和截图，均为隔离合成数据。不保存密码、token、认证状态或 HAR。原生系统分享只完成桥接回归，本轮没有 Android/iOS 编译、安装或接收应用验证。
