# AI-07 模型路由：服务与桌面检查点

本检查点仅记录独立模型协议、网关与桌面提供者的开发状态。移动端业务调用仍在接入；M3/M4 均未完成。

已实现：

- 独立 `model-invocations-v1` 契约与迁移 010，逐账号 RLS、身份/输入/配置/fence 固定、一次领取、取消墓碑和 24 小时逻辑内容有效期。与 PDF 解析、向量任务分开。
- 服务和网关分别默认关闭。网关使用部署者明确配置的端点/模型/密钥及具体 OIDC sub 白名单；没有全账号隐式计费授权。对模型只发送一次固定非流式请求，输出中实际私有密钥被替换后再保存。
- 创建数据库提交回复丢失时不启动模型；只读查询与精确重放不执行模型。收到结果后保存失败可备份内存候选或只重试保存。关闭会等待初始派发查询，晚到查询不能重新启动工作。
- 桌面账户页明确选择已保存 Chat Completions 预设，独立开启，无需先发布 PDF。每次启动/登录默认关闭；停用、配置/账号/文库变化与关机均停止本机等待。
- 系统加密保存私有凭据随机版本、执行意图和结果。缺失系统加密或明文后端时拒绝开启；记录最多 16 项，执行前预留完整结果空间。意图确认丢失时零上游请求，重开不补发；保存失败保留候选并提供恢复。
- 历史查看、原生 JSON 备份与只保存恢复已接入。保存对话框返回后重新检查账号和文库；取消/退出后不写文件。旧登录会话的记录仍可备份，不能被新会话静默接管。清理只处理明确已保存记录，未知执行记录保留。

网关未保存候选只在进程内存，退出即可能丢失，下载备份本身不释放候选。电脑端收到结果后磁盘写入失败的副本同样需要在当前进程中备份或保存。数据库 24 小时过期是读取限制；物理内容只在后续账号访问时清理，没有后台擦除承诺。
