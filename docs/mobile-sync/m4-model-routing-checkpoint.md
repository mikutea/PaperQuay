# AI-07 模型路由：服务、桌面与移动端检查点

本检查点记录独立模型协议、网关、桌面提供者与移动端四类业务路由。开发与隔离验证不能替代真实服务/设备验收；M3/M4 均未完成。

已实现：

- 独立 `model-invocations-v1` 契约与迁移 010，逐账号 RLS、身份/输入/配置/fence 固定、一次领取、取消墓碑和 24 小时逻辑内容有效期。与 PDF 解析、向量任务分开。
- 服务和网关分别默认关闭。网关使用部署者明确配置的端点/模型/密钥及具体 OIDC sub 白名单；没有全账号隐式计费授权。对模型只发送一次固定非流式请求，输出中实际私有密钥被替换后再保存。
- 创建数据库提交回复丢失时不启动模型；只读查询与精确重放不执行模型。收到结果后保存失败可备份内存候选或只重试保存。关闭会等待初始派发查询，晚到查询不能重新启动工作。
- 桌面账户页明确选择已保存 Chat Completions 预设，独立开启，无需先发布 PDF。每次启动/登录默认关闭；停用、配置/账号/文库变化与关机均停止本机等待。
- 系统加密保存私有凭据随机版本、执行意图和结果。缺失系统加密或明文后端时拒绝开启；记录最多 16 项，执行前预留完整结果空间。意图确认丢失时零上游请求，重开不补发；保存失败保留候选并提供恢复。
- 历史查看、原生 JSON 备份与只保存恢复已接入。保存对话框返回后重新检查账号和文库；取消/退出后不写文件。旧登录会话的记录仍可备份，不能被新会话静默接管。清理只处理明确已保存记录，未知执行记录保留。

## 移动端业务路由（2026-10-31）

已接入当前账号服务的独立能力协商与严格模型响应读取；远程路由配置只保存公开的目标/模型版本引用，不读取本机模型密钥，不把模型地址当成已授权网关。切换时保留直连公开配置，凭据命名空间不变；恢复直连必须明确操作。

PDF 阅读辅助、多篇问答、综述每段与模型 Agent 均传递其原业务请求 UUID。发送前核对原目标、配置版本、模型、输入摘要和输出预算，并在现有账号工作区事务中确认意图。未收到本机意图回执时零创建请求；服务创建回执丢失时保留原 ID，重开与再次查询只使用 GET，不自动派发排队任务。已知输出先落盘再传给业务组件；原来源失效仍可保留账号内结果，账号/会话改变后旧回调不能写入新账号。

私有账本最多保留 4 份完整输入/输出、128 份小型身份回执，总上限 3 MiB；发送前预留完整输出空间。未知执行会阻止新调用，只有明确承认既往费用可能已发生后才能解除本机阻塞。清理全文保留身份回执；同一 UUID 永不作为新的收费调用重发。完整记录与身份回执不进入同步 outbox，也不改动阅读游标、笔记或其他业务断点。手机端账本保存在应用私有数据库；本轮没有添加数据库静态加密，不与桌面的系统加密记录混称。

账号的模型设置可明确读取网关/电脑配置、核对后选择，查看原请求、取消、备份、仅重试本机保存、仅补存网关结果。执行原排队网关请求另有明确确认，并先查询其原状态。备份/查看不会应用模型建议到文库；重开后也不会自动把结果塞回已经变化的业务材料。服务 TTL 或较弱查询不能抹去已收到的本机/内存结果。
