# 模型 Agent：明确步骤与请求账本

账号页“文库 Agent”中选择文献后，打开“模型 Agent”。本机四规则继续独立可用；模型功能使用当前账号在此设备配置的服务，每次先显示模型、地址和确切消息，再明确发送。打开、刷新、重开或选择模型给出的分支都不会自动请求。

模型可直接回答、提出待核对计划、请求补充材料或给出可执行选项。结构化响应只接受已提供的文献ID及工具字段；未知ID、重复项、别名、额外字段和不支持的URL修改会整份停止。标题修改要求与捕获标题及实际update一致；最终差异由实际题录计算。题录字段建议明确标为未核验外部来源，不冒充成功查询。

## 从建议到应用

| 步骤 | 实际行为 | 恢复与边界 |
| --- | --- | --- |
| 发送预览 | 展示确切题录、批准片段、历史、模型与地址 | 输入、账号、来源或模型变化后旧预览失效 |
| 请求模型 | 先原子保存uncertain意图，再读取本设备密钥并发送一次 | 不隐藏重试、修复、换模型或自动工具循环；已发生用量以服务商为准 |
| 补充上下文 | 用户逐篇选择题录摘要或已核验的本机解析版本，核对实际文字后保存 | 缺缓存不改用摘要，不联网下载；保存后还需另预览与发送 |
| 用户选择 | 只填入模型给出的下一步指令 | 不把一次点击当作新的付费请求 |
| 计划送审 | 私有送审标记与待核对proposal同事务保存 | 不修改文库；只送审一次，不覆盖用户后来改过的计划 |
| 文库应用 | 返回原Agent工作区逐项勾选、预览，再原子写题录/outbox/回执 | 采用既有版本校验和原审批标识恢复，不重建已删除文献 |

最多64篇题录、快照1MiB；每次实际消息192KiB，最多8轮；补充来源最多8篇、各4000字符。显示源文字总量、未采用字符、实际页码、PDF hash和解析包摘要。题录摘要没有PDF页码，部分解析文字不称全文。超限停止并提示缩小范围，不静默截断选中文献。会话及收到的输出另受8MiB和192KiB等预算约束。

收到结果但本机保存未确认时，保留内存候选供“只重试保存结果”或JSON备份。文献变化不清除候选；账号退出或窗口关闭会结束该窗口的内存状态，界面先说明风险。未知请求重开不再发送；“标记为停止等待”仅记录本机决定，不声称服务商取消或退费。无效JSON保留为无效结果；异常控制字符及孤立代理字符会替换并标明诊断文本，不按有效计划采用。自然语言结果使用安全Markdown，模型图片及原始HTML不会自动加载或执行。

会话只在当前账号、此设备保存，不进入同步outbox。JSON包含题录、批准片段、确切消息、模型设置、结果状态及用量；不含PDF或密钥。当前仅保留一份会话，替换前可导出。审批回执保留来源计划、操作标识及内容摘要；跨会话的长期来源证据索引、外部题录补全与远程执行仍继续开发。
