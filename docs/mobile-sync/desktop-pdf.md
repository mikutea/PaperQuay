# 同账号在线电脑取文件 · M3

桌面「设置 → 账号与在线文件」已接入账号登录、选定 PDF 的题录/版本发布和临时文件提供。手机和平板的「从可用来源打开」依次读取本机缓存、同账号在线电脑、私有云、已填写的公开链接。首次进入阅读器仍只恢复缓存。

## 使用

1. 管理员为同步服务显式设置 `PAPERQUAY_DESKTOP_PDF_ENABLED=1`，并配置允许的桌面 OIDC public client。此开关默认关闭，与私有云开关独立。
2. 桌面填写与移动端一致的同步服务、身份服务，以及桌面客户端 ID；通过系统浏览器登录。
3. 在桌面文库导入 PDF，再在账号设置中选择附件，点击「添加并同步题录」。这里只发布选中文献的白名单题录和附件版本。
4. 若账号已有相同 PDF，可加载已有版本，点击「校验并关联」。文件长度与完整 SHA-256 必须一致，父文献与版本必须有效。
5. 开启「允许同账号设备取文件」，保持桌面应用运行。另一设备登录同一账号、完成同步后，在文件面板点击「从可用来源打开」。

每次桌面启动或重新登录后，文件提供都处于关闭状态，需要重新开启。关闭开关、取消传输、退出或撤销会话会停止提供。「停止提供」仅移除此电脑的关联，保留本地原文件和账号题录。设备列表的历史活动时间不作为在线证明。

## 文件与旧文库边界

电脑只接受服务器分配的附件版本 ID，将其映射到明确选择的本地 paper/attachment ID，再通过既有文件授权边界打开已导入文件。远端不能指定磁盘路径或 URL。文件句柄固定后重新读取完整字节并核对长度、SHA-256；文件变化会显示「文件已变化」，不能作为旧版本发送。

映射、同步 outbox 和操作 ID 按服务、账号和文库身份写入私有 profile，原子保存后才发出同步操作。题录确认后再发布附件版本；断线后的不确定结果保留原操作 ID，显式重试不会另建重复实体。冲突、永久拒绝和待重试状态保持可见，不会自动覆盖另一设备修改的题录。文库切换或数据库文件被替换后，旧映射失效。

本功能没有把整库、旧富文本、旧批注或阅读历史自动迁移到账号，也没有把远端编辑回写旧桌面 SQLite。不同内容应发布新附件版本；不会把旧坐标迁移到新文件。

## 登录与运行时

桌面主进程使用 `openid-client` 完成 Authorization Code + PKCE S256，通过随机端口的 `127.0.0.1` 回调接收授权码，并验证 state、nonce、ID token 签名和身份。刷新不能改变 issuer、subject 或 session。登录最多等待 120 秒，身份网络请求有独立时间及正文大小限制。令牌只保存在主进程内存；渲染器和同步实体不接收令牌，退出或重启后须重新登录。

配置要求 HTTPS，回环开发环境例外。身份服务端点必须属于配置的 issuer origin；不跟随跨域身份端点或网络重定向。参考 [RFC 8252](https://www.rfc-editor.org/rfc/rfc8252) 与 [openid-client](https://github.com/panva/openid-client)。参考 Keycloak 测试 realm 使用独立的 `paperquay-desktop` public client 和回环回调路径。

桌面构建会把共享同步核心编译到 `electron/generated/desktopSyncCore.cjs`；生成文件不入 Git。运行依赖 `openid-client`、`oauth4webapi`、`jose` 被明确纳入打包列表。隔离运行时依赖检查不等于已生成、签名或安装正式安装包。

## 临时中继

本轮使用 `http-relay-v1`：电脑从出站长轮询接收请求，将文件送到同步服务；服务以有界流转发给请求方。不会在数据库、磁盘或私有云副本中保存 PDF。服务可以看到传输内容；这不是端到端加密，也未实现设备之间的直接连接。

| 边界 | 当前限制 |
| --- | --- |
| 单文件 | 64 MiB；移动阅读器另有 2000 页限制 |
| 请求租约 | 最长 30 秒，并受已验证的令牌到期时间约束 |
| 提供方长轮询 | 最长 20 秒，在线登记最多 30 秒且不超过令牌有效期 |
| 并发请求 | 每账号 1 个、每服务进程 2 个；实际 I/O 与数据库操作结束才释放 |
| 提供方登记 | 每账号 4 个、每进程 32 个；每会话最多 1 个待处理轮询 |
| 请求内尝试 | 最多 4 个提供方，不重复尝试同一提供方 |
| 临时流量预算 | 15 分钟内每账号 256 MiB、每进程 1 GiB；按请求文件长度预留，取消不退回 |
| 客户端来源等待 | 缓存 5 秒、电脑 15 秒、云 15 秒、公开链接 30 秒；总上限 60 秒 |

提供方与消费方必须是同账号的不同已注册会话。下载只允许原请求会话使用一次，上传只允许分配到的提供方使用一次。服务持续复核会话及目标；同进程撤销主动取消，数据库只读复核也覆盖外部撤销。最后一块内容须在完整长度、哈希和最终权限检查通过后才写出。HTTP 写出完成仍不证明客户端已收到或解析成功，客户端继续核验完整文件并解析后再使用。

服务端文件列表、请求、轮询、上传、取消和错误码见 [服务说明](../../server/README.md)。能力协商返回 `features.desktopPdfTransfer:1` 与 `desktopPdf` 限制。旧服务不提供此能力时，移动端跳过电脑来源。

本轮为单进程内存 broker；重启会丢弃租约与临时预算，不支持跨进程分配。预算是防滥用边界，不是持久计费账本。生产代理必须支持长轮询和流式响应，并单独验证超时、缓冲、TLS 与外网链路。

## 验证范围

真实隔离 Electron、Keycloak、PostgreSQL、API 与独立 Chrome 客户端的结果见 [桌面文件检查点](m3-desktop-checkpoint.md)。原生文件选择器被限制为本次合成 PDF，系统浏览器启动入口被导向受控 Chrome context；授权跳转、回环回调、文件读取和 HTTP 传输都是真实执行。实际系统默认浏览器启动器、四类手机/平板、休眠唤醒、公网代理与签名安装仍未验收。
