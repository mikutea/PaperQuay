- 本设备独立 AI 服务、实际发送范围、真实 SSE、取消/失败恢复、版本绑定引用、结果保存笔记和内存上一结果。

## 本轮问题处理

1. AI 取消按钮已真实复测：取消只有一次 HTTP 请求，连接关闭，部分结果不再追加；显式重发产生第二次请求。
2. 离线 PDF 的根因是 worker 资源断网后无法加载；缓存字节/hash 正确。现打包有限离线资源，英文三页反复重开与断网后首次中文页渲染通过。
3. 全新文献第一次导入、旋转页区域锚点、安全 Markdown 预览、重复引用跳转、文件版本防串位与缓存清理均有浏览器证据。
4. 返回时 dirty 状态改为同步汇总；保存完成后一次返回成功，新草稿/未完成写入仍受保护。卸载提交立即使旧回调失效，相关竞态修复前失败、修复后通过。
5. 显式持有底层 Worker，未 ready 的取消/超时也精确终止；文本流取消传 Error，迟到分块被忽略，取消确认最多等待 2 秒。新增 12 项使用实际 PDF.js PDFWorker/MessageHandler 的回归。
