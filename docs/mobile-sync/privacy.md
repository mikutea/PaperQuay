# 个人数据与应用账号注销

设置 → 账号与设备 → 数据与隐私可查询账号、导出服务器及本机数据、重新验证登录和注销应用账号。账号已关闭而普通文库无法绑定时，登录页仍提供同一入口。

服务器导出格式和权限见 [服务接口](../../server/deploy/privacy.md)。客户端逐字节检查 JSONL 的账号、表、二进制顺序、每文件 SHA-256、最终数量和整流 SHA-256，且必须收到结束标记后的 EOF 才发布。截断、取消、切换账号和损坏均清理未发布文件。原生应用写入按账号散列隔离的私有临时目录，验证后才打开系统分享；分享完成后的文件在本账号缓存中等待显式清理。浏览器优先使用用户选择的文件目标；不支持流式保存时，内存下载上限为 16 MiB，超限明确失败。

本机导出另包含待同步队列、冲突、本机综述/雷达/Agent、问答记录与模板、解析包和缓存 PDF，包括当前文库已无条目的孤立缓存。使用结构化路径逐项输出和有界文件块，校验各存储在导出前后没有变化后写完整收据。不会把无法读取或缺失的缓存静默当成成功。凭据、私有下载 URL/路径及执行授权字段排除；每条 JSON 行仍有 8 MiB 上限，原生和支持文件目标的浏览器不需在内存汇集整库。

注销分别确认应用账号及云副本、本机私有副本与凭据、所有已绑定设备的后续清理。最终需输入带账号 UUID 的确认文字。账号和请求 UUID 在首次 POST 前持久保存，未知结果只允许查询或显式重试同一请求，不自动重放写操作。重新认证使用系统浏览器 Code+PKCE、`prompt=login` 和 `max_age=0`；服务仍独立核实五分钟内的签名 `auth_time`。

本机清理必须先匹配当前 OIDC 主体名下、过去经服务端验证的本机绑定，不能只用状态响应中的账号 ID 选择缓存。先停止文库操作，清理账号结构化数据、全部 PDF（含离线保留）、解析包、问答、本账号导出临时文件和注册的模型/Zotero/雷达凭据；全部成功后才用原 SID 确认本设备。映射在 ACK 前保留，以便网络失败后重试。清理失败或账号切换不发送成功确认；其他账号和用户原始文件保持独立。凭据地址登记在安全存储，登记先于保存，清理与所有已开始写入串行化。

凭据登记覆盖此版本开始创建/访问的密钥及当前旧配置仍引用的密钥；没有提供已卸载试验包、系统备份或 OS 历史快照的擦除证明。该移动版本尚无用户实机安装迁移；旧试验包如果留下无法枚举的系统凭据，应在隔离重装验收中明确处置，不能用本次 ACK 宣称已擦除它们。

原生安全存储还保留先于写入的地址清单，账号清单保留更换模型端点前的历史地址。注销前枚举本应用前缀下的系统键并核对清单；发现旧版本未登记、无法归属的键，或枚举/清单失败，均不发送擦除 ACK。能恢复准确旧端点与账号归属时才登记并删除对应键，不能全局删除或猜测其他账号。历史地址和清单在系统安全存储中保存，不含密钥正文，不进入同步或普通日志。

浏览器把已由服务端验证的主体与账号/设备映射单独存入 IndexedDB；命名空间隔离 API、issuer、client 和 subject。各登录会话另按不可用于认证的 SID 散列保存自己的设备绑定，另一标签页写入同一主体的恢复映射不会替换当前会话的 ACK 设备。清理只条件删除本会话及对应恢复映射，保留其他会话的新记录；旧版仅有主体映射的记录只允许本机清理，需重新从服务验证后才能用于 ACK。映射不包含原始 SID、访问/刷新令牌或模型密钥，浏览器凭据仍仅驻留内存。刷新后即使账号已注销、注册被拒绝，原主体重新登录仍能明确清理残留的本机数据；新登录不会替原 SID 确认旧设备。完成清理后才删除映射，持久化不可用时明确失败。

隔离验证已覆盖完整性、未知响应与请求重启、A→B→A、原绑定校验、分阶段清理失败、迟到凭据写入、ACK 失败重试与外账号保留。真实浏览器检查 320/768 像素布局、深色可读性、44 像素以上按钮、确认焦点、Escape 和返回入口焦点；这些属于合成组件验收，不证明真实身份端到端、VoiceOver/TalkBack、四类实机、系统任务预览或 iOS 签名验收通过。

补充合成界面核对：320×740 与 768×1024 下将根字号放大到 32px，浅色与减少动画下无页面或弹窗横向溢出，确认流程可用键盘退出并恢复入口焦点。窄屏采用固定边距与有界内边距，避免放大字体同时挤占控件宽度；320px 深色默认字号也无横向溢出。浏览器尺寸、主题和动画模拟在验证后恢复，不把这些结果当作系统读屏或实机证据。

后续复审补充：自动出现的隐私处理窗口会保持到用户关闭或安全退出，不因停止同步而消失。持久 OIDC 会话删除成功前保留验证绑定和恢复界面；删除后才以原会话的临时访问令牌确认设备，确认完成后清除绑定及内存会话。删除或确认失败均可显式重试，不将失败发布为已退出。

所有普通 Markdown/JSON/书目/DOCX 导出也写入 `paperquay-exports/<账号与服务散列>/<任务>/`。清理先停止接收该账号的新导出，等待已开始的文件写入结束，再删本账号目录；其他账号的目录保留。旧试验版本若有无法归属账号的导出目录，清理明确失败并保持待确认，不能猜测所有者或以全局缓存删除代替账号隔离。用户已另存或第三方应用已接收的副本不属于本机私有缓存的擦除范围。

已归属本账号的原生“待处理分享”内容也在持久会话删除及 ACK 之前原子清理。专用 owner-only 操作保留未归属和其他账号的内容，清理期间阻止旧客户端继续读取或认领；失败可显式重试。损坏或曾隔离的快照无法证明账号归属时保持待清理，不自动删除其他材料，也不确认完整擦除。

注销清理还在 PDF、解析包、问答及账号快照的各自持久事务中留下最小的不可复写标记。其他浏览器标签页或旧缓存 handle 在清理后完成下载、解析、模型保存或 outbox 写入时会被拒绝；普通“清缓存”不移除该标记。新账号和其他服务独立保留。原生 PDF 的两份恢复清单同样保留该屏障，不能用旧清单恢复已擦除数据。

浏览器各页还会在载入已验证账号的私有内容前持有共享 Web Lock。擦除先持久保存不含凭据的账号标记，再要求其他页停止私有视图和请求、删除各自内存中的模型、Zotero、雷达密钥及普通会话。发起页只有取得排他锁后才允许发送设备 ACK；冻结、无响应或清理失败的页面仍持有锁，等待超时会保留“待完成”，不能通过租约过期或抢锁跳过。请访问或关闭相关页面后显式重试。

同一页面内更换运行时或账号也保留各自的内存归属，旧运行时先销毁私有视图、认证、存储 handle 和内存密钥，再释放锁。晚到的模型请求、来源请求、密钥读取、配置保存和文库写入都检查擦除标记；正在执行的账号请求会收到取消。浏览器需要可用的 Web Locks 与本地存储，并以顶层页面运行；缺少这些条件时不载入私有工作区，也不会降级确认擦除。该机制不提供操作系统内存取证、历史快照或系统备份的物理擦除证明。

已通过保存前检查的另一页模型设置仍可能在首轮清理后才完成同步写入。因此每个页面在释放共享锁前还会清理该账号的普通与外部模型配置；配置删除失败时继续持锁，保持待确认。发起页取得排他锁后再清理一次共享配置，再发送 ACK，其他账号的设置保留。

擦除确认失败后若访问令牌过期，客户端仅允许使用仍在内存的原刷新令牌续期，严格保持 issuer/subject/SID；新令牌不写回系统存储，仍只用于擦除 ACK。网络失败可显式重试。身份服务已使原会话失效或应用进程已丢失临时凭据时，设备仍为待确认，不能用新登录 SID 代替原会话。

开始擦除时若普通刷新正在轮换令牌，先阻止普通凭据调用，等待并验证该轮换的同一会话结果，再删除持久凭据；不能丢弃服务端已经消费的旧刷新令牌所对应的新凭据。替换账号或销毁运行时会中止等待中的擦除；普通退出仍立即使迟到刷新失效。

本机清理失败后，运行时为原认证周期保留已经核实的注销状态与恢复绑定。关闭后重新打开窗口会显示上次状态及明确重试入口，不通过普通访问令牌重新查询，也不自动重放清理；重新认证按钮暂时禁用，避免丢失待确认的原会话。切换账号（包括 A→B→A）、销毁运行时或清理成功会使该内存恢复状态失效。缓存状态不当作最新设备统计。

同一账号在另一标签页使用独立 SID 时，该页先停止普通状态查询、导出及文库操作，等待正在进行的导出写入及临时目标清理完成，再删除持久凭据和内存业务密钥并释放共享锁。该页仅在内存中保留被阻止普通调用的原会话，不替发起页确认。用户明确同意后，以本页原会话向服务核实账号和同一注销请求 UUID，清理残留后确认自己的设备。未知确认结果保留恢复入口，允许关闭窗口后重新打开并显式重试；新账号不会继承原会话的业务封锁。正在轮换令牌的普通请求被拒绝时，也不把可恢复清理状态发布成认证错误。
