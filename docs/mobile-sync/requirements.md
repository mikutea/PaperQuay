# 完整功能清单

阶段表示计划完成点，不表示当前已经实现。所有用户内容默认私有；协作共享、收费订阅和商业运营后台不属于本轮必需范围。

2026-10-26 的 M2 实现与证据按 [M2 验证记录](qa/m2.md) 逐项追踪。原生工程及适配器已接入，真实设备本轮按用户要求暂缓；不能把对应行的阶段标记解释为实机验收通过。LIB-02 当前同步新客户端的分类字段，旧桌面 Reader 的分类/正文双向回写仍属于后续接入范围。

## 实施约束

1. 完整业务目标不等于所有计算都在手机执行。解析、向量检索和批量任务可使用明确选择的服务器/电脑。
2. 用户主动上传 PDF、向模型发送文本、同步个人记录是三种不同授权；不能相互替代。
3. 公共链接可能失效、受登录限制或 CORS 限制。不可获取时展示原因和可用替代方案，不承诺全部文献都能直接在线打开。
4. 不将未知版本旧批注、路径派生 ID、API headers 或团队共享数据混入个人同步。
5. 商用品质要求以 [验收标准](acceptance.md) 为准；本清单没有给出未经负载和实机验证的 SLA 或容量数字。
