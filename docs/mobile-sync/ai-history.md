# 本机问答记录与问题模板

在 AI 助手展开「本机问答记录与问题模板」。记录保存一轮独立问答，可离线重看输入和结果；问题模板用于复用问题。查看或应用模板不会请求模型，只有上方明确发送才产生请求。

## 保存与重开

- 请求结束后点击「保存此问答到本机记录」。保存实际发送的问题、输入原文、PDF 版本与 hash、解析包摘要（如有）、模型公开引用、开始/结束时间、结果和终态。后来修改输入框不会改变这条记录。
- 完成、失败、不完整、已取消分别保留原状态。生成中不能归档；取消后的部分文字不会变成完成结果。重复保存相同问答不会增加副本。
- 记录是当时的快照，解析缓存以后替换或清理也不改写记录。页码引用从保存的输入重新派生；当时没有提供的页面没有回跳按钮。
- 阅读器当前选择了相同文献、PDF 版本及 SHA-256 的文字时，历史页码可以回到该 PDF。当前来源缺失或不同版本时只允许查看记录，回跳按钮禁用。
- Web 刷新需要重新登录；同账号在同一浏览器登录后可重新打开记录。已加载应用断网后可读取本机记录，这不代表离线冷启动已验收。

## 问题模板

从当前问题创建模板，填写名称、任务与问题后保存。选择模板后「填入当前问题」只填输入框；已有不同草稿时先确认替换。模板也可编辑或删除；并发窗口修改会拒绝过期写入并保留正在编辑的草稿，需要重新读取后处理。

模板不绑定旧 PDF 文字，也不替换当前模型、密钥或发送范围。发送前核对当前文献和范围。历史问题也可以单独填入当前输入框。

## 存储与清理

记录和模板按「同步服务地址 + 账号」隔离，只存本设备。Web 使用独立 IndexedDB；原生工程接入账号 SQLite，原生持久表现仍待实机。每账号最多 50 条问答、100 个模板、共 16 MiB；单条问答最多 1 MiB，单模板最多 16 KiB。达到额度会明确拒绝，不静默删旧记录；存储失败不降级为假成功。

记录包含实际输入原文和模型返回内容，请按个人阅读资料管理。本实现不保存 API 密钥、令牌或其他凭据配置；只记录服务 ID、基础地址和模型 ID。用量只显示服务商确实返回的数据，费用始终标为未知。

删除单条和清空问答/模板都需要确认，不删除 PDF、文献笔记、模型设置或当前问题。账号页「清除此账号的本机副本」会一并清理问答与模板，并撤下已打开的旧记录。排队写入受到清理代次保护，不能在删除或清空后复活旧记录。损坏存储会明确报错，仍可清理当前账号恢复使用。

问答和模板目前没有云端副本、导入导出或多轮会话恢复；另一设备不会自动收到。已另存为文献笔记的内容继续按笔记协议同步。AI-04 当前只完成本机独立问答与模板这一部分，跨设备会话与桌面业务仍待后续设计及验收。
