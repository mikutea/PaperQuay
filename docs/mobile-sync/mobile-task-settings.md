## 在原任务里配置 AI

多篇文献问答、文献综述和模型 Agent 顶部提供“设置 AI”或“更换 AI”。打开后可选择账号或电脑提供的模型，或填写自己的服务地址、访问密钥与模型名称。

设置面板叠放在原任务上，保留已选文献、问题、综述材料与未应用的蓝图/章节编辑，以及模型 Agent 的会话和指令。完整保存成功后自动返回原任务；手动返回也保留任务草稿。设置表单本身有未保存修改时沿用放弃确认；失败时保留可编辑内容，不显示为保存成功。

返回后需要重新预览实际材料、模型和目标，再明确发送。打开设置立即废止旧发送预览，即使没有更换模型，旧发送回调也不能继续发起请求。单纯配置、取消或返回不会调用模型。

已有问答结果不会因打开设置而清空；正在请求或存在尚未确认保存的模型结果时不可切换设置，仍使用原有停止、只保存恢复与备份路径。账号、文库和原始请求的隔离规则保持。

设置入口显示的是保存的模型名称，不等于服务可连接或密钥已验证。密钥由现有系统安全存储或当前页面内存保存，不进入普通本地存储，也不随任务草稿同步；浏览器刷新后可能需要重新填写。
