# M3 外部文库快照映射检查点 · 2026-10-28

后续更新：版本绑定的解析阅读已有实现与局部验证，见 [M3 解析阅读检查点](m3-parsed-checkpoint.md)。以下保留外部库阶段证据。

“导入与导出 → 外部文库”已支持同一来源的重复导入与题录更新。用户选择快照，比较来源、本地与上次基线，再确认保存；来源条目始终映射到稳定的 PaperQuay 文献 ID。四类实机按用户要求继续暂缓，M3 尚未整体完成。

## 已实现范围

- 读取 Zotero Web API v3 JSON 条目数组，以及明确版本的 PaperQuay 外部文库快照 v1；来源由种类、库键和条目键识别。每次最多 4 MiB、500 条，拒绝非法 UTF-8、混合来源、重复键及不合法版本。
- 标题、DOI、年份、出版来源、摘要、作者和关键词按三方比较合并。仅本地修改的字段保留；同字段冲突必须明确选择；个人收藏、标签、合集、队列和阅读状态保持本地值。
- 重复候选必须明确关联已有文献、另存副本或跳过。重复快照不新增题录，不重复创建待发送操作；旧版本不回退基线，同版本不同内容会被阻止。
- 已删除、不可见或有未完成同步/冲突的目标禁止更新。来源缺少某条记录不删除本地文献。题录与来源映射一对一，防止同批来源争用目标。
- 预览绑定用户实际比较的工作区。后续本地或同步变化使预览过期，保存禁用；重新比较会清除旧关联及冲突选择。提交在事务内再次核对账号、设备、generation、目标与完整计划。
- 来源映射、版本基线、混合新增/更新题录和 outbox 在一次事务中落盘；失败全批回滚。同步失败保留已保存内容并阻止后续来源版本绕过待处理状态。

来源映射只保存在本设备当前账号下；题录正常同步。另一设备需要重新选择来源并明确关联已有文献。没有外部账号登录、后台轮询、附件读取或回写；格式细节、限制及恢复边界见 [外部文库快照映射](external-library.md)。

浏览器入口为 `http://127.0.0.1:4317/` 的生产预览，使用隔离合成账号和独立浏览器 context。当前没有 Browser 插件，按 frontend-testing-debugging 技能使用已安装 Playwright 与独立 Chrome。实际执行文件选择、持久化和同步，没有代替应用提交逻辑。

数据场景覆盖 Zotero 字段省略提示、刷新后重新登录仍保留映射、同快照幂等、本地标题/收藏/标签保护、另一客户端编辑使预览过期、重新比较清除选择、旧版本及同版本篡改被阻止、第二设备显式关联而不重复、混合来源/非法 UTF-8 无写入、真实 IndexedDB 中途 abort 后三部分共同回滚，以及已加载应用离线导入后重连同步。第二设备收到题录但没有收到第一设备的来源映射。

首轮脚本误假设 Web 刷新后仍保持登录；产品原有内存凭据要求重新登录，已改脚本走实际登录/SSO。第二轮脚本对摘要控件使用过严的完整标签定位，已调整定位；这两次没有产品修改，原始失败记录保留。最终成功运行仍记录一条同步 pull 的 `net::ERR_ABORTED`，后续同一客户端双向同步成功；页面异常、console 错误和 HTTP 错误均为零，不把网络失败计数写为零。

源码阶段修复了预览工作区变化后仍沿用旧选择的问题，并补回归；重复候选索引改为原地追加，避免反复复制数组。最终全量结果以本检查点为准，不以先前定向测试数代替。

截图复核另发现 320×640 初始预览的保存按钮被父容器边界裁切约 11.47 px。已将保存区移为整个外部库面板的直接子元素，保持提交逻辑和顺序不变。最终生产预览的按钮 y=569..613，完整可见；最后一项内容底部在按钮顶部之上，200% 字号亦通过。修复前证据保留，修复后 16 张截图与实际键盘、滚动测量另存，类型检查与生产构建再次通过。

本地证据位于 `PaperQuay维护/20261023_移动端与账号同步/qa/m3/20261028/external/`，包含原始日志、浏览器结果与失败尝试、截图、独立复核和最终文件哈希。证据目录不随源码提交。
