# 文库与书目文件交换 · M3

移动文库与笔记页的“导入与导出”入口支持 PaperQuay 文库 JSON、Markdown、BibTeX 和 RIS 文件，也可以显式查询 Crossref DOI 题录。此功能属于 M3 文库接入；电脑取全文、直连/中继、私有云、外部文库持续映射、完整富文本和远程解析仍按原计划推进。

## 使用与范围

选择文件后先预览，默认选中新内容、跳过重复项。勾选重复项会使用新 ID 另存副本。关联笔记会明确显示连接到本次文献还是现有文献；缺少文献、存在多个匹配或未选中必要文献时，必须处理提示或取消该笔记后才能导入。

导入只创建记录，不覆盖、恢复或合并已有记录。当前账号和设备绑定、预览结果与内容关联在提交事务中重新检查；发生变化会保留预览并要求重看。整个批次与待同步队列一次保存，本地事务失败不会出现部分导入。保存完成后按既有同步协议继续发送，不能把本地保存当作服务端已确认。

单次最多 4 MiB（UTF-8 字节）、500 篇文献、500 条笔记。文件须为有效 UTF-8 文本，错误编码不会替换成乱码后继续保存。题录与笔记字段沿用同步协议的长度和结构限制。Markdown 文件保留正文，文件名作为笔记标题，创建独立笔记；不推测 front matter 中的文献 ID。

文库 JSON 导出当前设备已保存、未删除的题录与 Markdown 笔记。包括尚未同步的本机改动；存在冲突时明确提示导出当前可见内容。未保存草稿、PDF、批注、阅读位置、AI 会话和账号/设备/凭据配置不在此格式内。单篇 Markdown 导出保留正文；标题用于文件名。

导出使用文件内 `p1` / `n1` 引用，不携带原账号、设备、实体或操作 ID。关联文献缺失时仍保留待核对的文件内引用；不会静默将笔记改成独立笔记。导出的文本内容属于用户提供的题录与正文，内容本身可能包含用户主动记录的个人信息。

## 格式 v1

```json
{
  "format": "paperquay-library",
  "version": 1,
  "papers": [
    {
      "ref": "p1",
      "data": {
        "title": "研究示例",
        "authors": ["示例作者"],
        "year": "2026",
        "doi": null,
        "publication": null,
        "keywords": [],
        "abstractText": null
      }
    }
  ],
  "notes": [
    {
      "ref": "n1",
      "paperRef": "p1",
      "title": "阅读记录",
      "body": "# 阅读记录\n\n待核对的研究想法。",
      "format": "markdown"
    }
  ]
}
```

题录允许同步协议定义的 `organization` 分类字段；只有服务声明支持，或离线时已有可用的能力记录，才允许导入分类。已明确返回不支持的旧服务不能通过断网绕过检查。未知字段、版本、重复引用、非法 ID 或超出长度的内容明确拒绝。

去重优先使用规范化 DOI；没有可用 DOI 时，逐字比较标题、作者、年份、DOI、出版来源、摘要和关键词七个字段，不将个人分类作为书目身份。仅标题相同不会自动归并。笔记比较关联文献、标题和完整 Markdown；重复项仍需用户主动勾选才会新增副本。

因此同一 JSON 内无 DOI、题录相同但分类不同的两篇文献，默认只选择一篇；对应笔记可能关联到同一匹配对象。预览会说明题录重复、分类不自动合并。明确勾选全部副本会保留各自分类和笔记关联。已有多个匹配对象时，关联仍被阻断，不能任意选择一个。预览签名继续包含完整分类；预览后只改变分类也会使原预览失效。

## BibTeX 与 RIS

使用 `.bib` / `.bibtex` 或 `.ris` 文件导入。BibTeX 使用锁定的 Citation.js 语法解析器及有界结构检查；RIS 按条目和标签边界读取。不会将文件内容自动识别为网络地址、执行 LaTeX 命令、读取附件路径或连接外部库。缺少标题、畸形条目、无效 DOI、字段超限时拒绝整个文件。

可保留的内容限于上述七个书目字段。文献类型、卷期页、出版商、引用键、资源链接及其他未支持字段在预览中逐条提示，不会塞入同步 ID。作者保存为有序显示名称；姓/名结构、机构标记及格式变化会明确提示。已识别的 LaTeX 格式可转为文本；未支持命令保留字段原文并警示。日期只取年份，换行或连续空白的转换也会提示。

导出可选择全部已保存文献或单篇，格式为 BibTeX / RIS。只有文献数及题录体积参与书目导出上限，无关笔记不会占用该额度。当前协议没有文献类型，统一导出通用 `@misc` / `TY  - GEN`；不会推测为期刊论文。作者以字面名称保护，字段转义避免新条目或新标签注入。分类、笔记、PDF 和原库内部标识不在书目文件内；需要当前分类和 Markdown 时使用 PaperQuay JSON。

这是一份可预览的题录交换，不是 Zotero 全库迁移、持续同步、完整引文样式引擎或无损外部库备份。导出的标准书目可以被相应格式工具读取，实际 Zotero 客户端的全字段导入仍需单独验收。格式依据见 [Zotero 书目格式说明](https://www.zotero.org/support/dev/data_formats) 与 [Citation.js 官方项目](https://github.com/citation-js/citation-js)。

## DOI 查询

“DOI 查询”接受裸 DOI、`doi:` 前缀或 `doi.org` / `dx.doi.org` 链接。仅用户点击查询时向固定 Crossref HTTPS 接口发送规范化 DOI，不携带本应用的账号令牌、Cookie、Referrer 或题录正文，不抓取输入 URL，也不跟随重定向。取消、关闭面板和账号变化会中止或丢弃旧结果；旧请求的收尾不能解除新请求的忙锁。

查询默认 10 秒超时、响应最多 1 MiB；核对返回 DOI 与查询完全一致后才生成预览。出版年份优先使用 `issued`，再按已记录的出版日期回退，绝不使用收录/更新时间冒充出版年份。缺失作者、年份、出版来源和摘要明确提示；复杂 JATS 摘要不支持时保留为空并说明，安全文本转换不执行 HTML 或加载图片。

查询成功不等于已入库。用户仍须检查题录、字段变化和重复项，再点击导入。404、429、网络故障、超时、响应不一致或超限均不写入文库，也不自动无限重试。Crossref 不能覆盖所有 DOI 注册机构；无法查询时可改用出版方书目文件或手动编辑。

## 平台行为

Web 通过浏览器下载 JSON、Markdown、BibTeX 或 RIS。原生容器使用 Capacitor Share 与 Filesystem Cache，并保留对应扩展名；只有用户点击导出才打开系统选择器，不会自动选择接收应用。文件准备完成后再次核对账号，过期准备会清除临时文件且不打开分享。

分享面板返回不能证明接收应用已经读取文件，所以已交给分享面板的文件留在系统管理的缓存中，避免过早删除造成空文件。系统可能随后清理缓存；下载或分享出去的文件不再跟随账号同步或清理操作撤回。原生分享的桥接测试和工程插件同步不替代真实设备的保存、取消与接收应用验证。
