# 原生连接状态

Android/iOS 使用原生 Network 插件读取和监听设备连接状态；Web 浏览器保留 `navigator.onLine` 与在线/离线事件。原生启动在系统读取完成前按离线处理，不用 WebView 的在线标志覆盖系统断网结果。

回到前台时先重新读取设备连接，再触发原有恢复逻辑；较新的系统事件优先于尚未完成的旧查询。退出工作区后忽略延迟结果并移除本次监听，不清除其他插件使用者的监听。

设备连接只是一项提示，不代表身份服务、同步接口或外部提供者已可用。存在 Wi-Fi、蜂窝或其他活动链路时保留对私有服务的访问；不要求公共互联网验证成功，也不主动发送探测请求。没有活动链路时保留本机阅读与编辑能力，停止自动同步。

自动化回归覆盖原生/浏览器来源隔离、连接切换、前台重读、乱序查询、延迟清理、读取失败和仅局域网链路。原生系统交互、四类实机、账号服务链和完整 T25 仍分别记录验收证据。
