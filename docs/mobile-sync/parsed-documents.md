# 版本绑定的解析包

桌面为已关联到账号的 PDF 导出解析包，移动阅读器在打开同一版本后主动导入。包内包含文本、公式、表格和位图；保存后可在本设备当前账号中离线重开。解析包目前通过文件交接，不会自动同步、上传或请求远程解析。

## 操作路径

1. 桌面从已导入的 PDF 发起新的 MinerU 解析，记录实际上传字节和本次产物的摘要；每次结果使用独立目录。
2. 在「设置 → 账号与在线文件」为附件建立或选择已发布的账号映射，点击「导出解析包」。
3. 手机或平板打开同一 PDF 版本，进入「解析」或「更多阅读选项 → 解析阅读」，选择 JSON 文件。
4. 完整校验后原子保存。按解析页阅读，点击内容块回到 PDF 原文页；平板可并列查看，手机在面板中切换。

旧缓存、手动附加 JSON、缺少原始上传版本证据的结果不会被补写为可信，需重新解析。系统安全存储不可用时仍保留成功的桌面解析，但不能导出可验证解析包。

## 内容和存储

| 内容 | 本轮行为 |
| --- | --- |
| 文件身份 | 文献 ID、附件版本 ID、PDF SHA-256、字节数和真实 PDF 页数；移动端与已打开文件逐项比较 |
| 来源证明 | 主进程对同次上传和 ZIP 产物生成 HMAC 证据；密钥由系统安全存储保护，不提供 renderer 签名接口。导出复验当前授权、文件和产物摘要 |
| 文本与公式 | 保留结构块和数学 Markdown，独立公式保留 LaTeX；KaTeX 关闭 trust 并限制展开与尺寸，失败保留可读源文 |
| 表格 | 保留行列跨度、表头/表身/表尾、标题和脚注；无法表达的嵌入对象或复杂表格明确拒绝，不静默删内容 |
| 续页 | 读取包内同类型来源块内容，保留当前块 ID 和当前页跳转目标 |
| 图片 | 仅包内 PNG/JPEG/WebP，核验头部、尺寸、字节数和 SHA-256，再由浏览器实际解码；失败、切换和关闭释放 Blob URL |
| 定位 | 本轮按页定位，不猜测转换 MinerU bbox、旋转或 CropBox 坐标 |
| 缓存 | Web 独立 IndexedDB、原生独立 SQLite，账号与服务隔离。正文和目录原子保存；容量检查只读目录，旧 v1 缓存一次升级至 v2 |
| 失败与清理 | 失败保留旧包；损坏缓存无需加载成功即可清理。单版本或全账号解析清理均不删除 PDF、笔记、文库或导出原件 |

`paperquay-parsed-document` v1 使用闭合 JSON。未知字段、重复键、无效 UTF-8、异常引用和超限数据均拒绝。包摘要由规范 JSON 计算，资源另有摘要；这些摘要用于完整性核对，不是云端第三方认证。

导出不携带本机资源路径、API token、下载地址或原始 OCR 对象。本机资源目标不能作为 Markdown 链接或图片引用离开桌面；普通正文按受支持语义保留。移动端跳过原始 HTML，不加载 Markdown 远程图片，链接只在用户点击时打开。

取消、账号或目标变化会中止尚未提交的工作。事务提交调用开始后不承诺撤销已经提交的本机数据，迟到界面结果仍被隔离。

## 固定限额

| 项目 | 上限 |
| --- | --- |
| JSON | 16 MiB；深度 20、节点预算 300,000 |
| PDF 身份 | 64 MiB、2000 页 |
| 内容 | 20,000 块、总 2,000,000 字符；单块 100,000 字符、LaTeX 16,384 字符 |
| 图片 | 64 张、单图 2 MiB、合计 8 MiB；边长 8192，单图 16 Mi 像素、合计 32 Mi 像素 |
| 表格 | 单表面积 10,000、总面积 100,000，结构与跨度同时核验 |
| 本机账号缓存 | 64 MiB、32 份；满额拒绝，不自动驱逐或截断 |
| 渲染 | 当前页每段最多 40 块，可继续翻段 |

SVG、动画图片、任意外部资源及无法完整表达的表格结构不受支持。解析包文件由用户保管，清空缓存后需重新导入。

本轮不包含解析包在线传输、远程解析任务、向量索引、解析文本进入 AI 上下文、完整富文本笔记或真实 MinerU 服务验收。四类实机、系统文件选择器、后台/终止恢复、外网、签名安装及升级继续待验收。Web 离线限已加载应用，没有离线冷启动 PWA。

数学渲染配置依据 [KaTeX 官方选项](https://katex.org/docs/options.html)。实际验证状态见 [解析阅读检查点](m3-parsed-checkpoint.md)。
