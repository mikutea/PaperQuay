# 开发计划

截至 2026-10-25：M0 已完成；M1 的服务、共享核心和响应式客户端已实现，并完成本机真实 OIDC/PostgreSQL、独立客户端同步及故障验收。详见 [M1 验收记录](qa/README.md)。当前提交的 CI 与代码/安全审查由 [PR #34](https://github.com/mikutea/PaperQuay/pull/34) 跟踪；M2–M5 尚未执行，不将浏览器界面作为原生设备验收。

## 实施顺序

| 阶段 | 产物与主要范围 | 进入下一阶段的条件 |
| --- | --- | --- |
| M0 需求与设计 | 完整需求、验收矩阵、身份/同步契约、手机和平板界面方向 | 需求 ID、数据边界、已知风险和首批范围可审阅 |
| M1 账号与同步基础 | 自托管 OIDC 接入、PostgreSQL 变更日志/CAS/幂等、账号隔离、设备会话撤销；可运行响应式客户端；持久 outbox；桌面白名单投影 | 真实身份服务+数据库的两个独立客户端同步通过；冲突/删除/重试/隔离有自动化证据；桌面原数据不变 |
| M2 阅读、笔记与 AI 核心 | iOS/Android 原生容器、安全存储、按需 PDF、位置与划线、自动保存、外部模型 API、手机/平板布局 | 四类实机完整阅读闭环；电脑离线时外部 API 可用；网络/进程中断恢复；PDF 版本不串位 |
| M3 全文来源与完整文库 | 在线桌面取文件、直连/中继、可选私有云、导入导出、外部库、解析视图、无损富文本笔记与远程解析 | 来源/版本/配额/授权/撤销故障矩阵通过；存储与带宽实际可计量 |
| M4 桌面业务对齐 | radar、多篇问答、Agent、综述、知识图谱、批量任务；移动执行能力与远程任务适配 | 功能清单逐项对照，无静默缺功能或假按钮；业务结果与桌面一致 |
| M5 正式可用验收 | 可访问性、真实性能、恢复/升级/回滚、监测、隐私导出、签名发布、外网实测 | 商用品质验收全部达标，剩余风险明确关闭或限定范围；生产部署另留记录 |

按依赖推进，不给没有人员、服务容量和真实设备证据的固定上线日期。每阶段形成独立可运行成果、测试记录和 PR；有失败证据时先修复该阶段的根因。

## M1 具体实施边界

- 先启用 `paper`、`attachmentVersion`、新 Markdown `note`、版本锚定 `annotation` 与每设备 `readingPosition` 五类协议实体。UI 首批暴露文库和新笔记同步；Reader 真正生成坐标的入口在 M2 接入。
- OIDC 使用成熟身份服务；业务 API 不自制密码数据库。第一批设备管理指可验证的登录会话，不能把任意客户端传来的 deviceId 当身份。
- PostgreSQL 是服务端持久化真值。单元测试替身只验证局部行为；集成验收使用真实 PostgreSQL 和身份服务。
- 客户端按账号保存数据、outbox、cursor 和冲突；本地编辑先落盘。浏览器原型使用 IndexedDB，原生持久层/系统安全存储在 M2 实测后接入。
- 桌面第一批交付可重复的白名单投影及稳定映射；未知历史版本、独立路径工作区和不支持的富文本明确报告 skipped。首批不把服务端快照回写旧 SQLite。
- 不在 M1 自动上传 PDF、迁移真实库、开放公网服务或宣称 iOS/Android 原生验收完成。

## 模块所有权与集成

| 模块 | 责任 | 主要交界面 |
| --- | --- | --- |
| 账号与同步服务 | 身份验证、服务端事务、迁移、访问隔离、API 集成测试 | 冻结的协议 v1 与 JSON 字段白名单 |
| 跨端同步核心与桌面投影 | ID/版本映射、状态机、幂等 outbox、投影/隐私测试 | 无 Electron/文件系统依赖的纯模块 |
| 移动客户端 | 响应式工作台、登录、文库/笔记、同步与冲突操作 | 平台适配器和同步核心 |
| 集成与验收 | 需求追踪、视觉、独立服务环境、端到端与仓库检查 | 精确提交的证据与 PR 审查 |

本次并行子智能体统一使用用户授权的 `gpt-6-astra / max`。该选择只对本次开发有效。

## 交付门禁

1. 运行适用单元/协议/数据库集成/端到端检查，再运行仓库规定的全部 Node tests、TypeScript 和 Vite production build。
2. Reader UI 改动需隔离 Electron 验证；原生改动需实际平台验证。浏览器截图不能替代 iOS/Android 或 Electron 交互证据。
3. 为改动创建 PR，每次 push 等待当前 SHA 的代码与安全审查；逐条处理有效 P1/P2 与其回归测试。通过 CI 不等于审查完成。
4. 本轮开发不自动合并、发布或部署生产服务。先提供具体可审阅版本；涉及生产的后续动作按用户已有授权和明确范围执行。
5. 产物记录代码已实现、自动化已验证、实机已验证、生产已验收四个维度。未测就是未测。
