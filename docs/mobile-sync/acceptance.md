# 验收标准

每次验证记录提交 SHA、环境、步骤、输入数据、预期、实际和证据路径。除明确记录通过的项目外，初始状态均为 **待验证**。所有破坏/中断测试只使用合成库和隔离配置。

| 验收 ID | 对应能力 | 必须执行的场景 | 通过条件 |
| --- | --- | --- | --- |
| T01 | ACC-01/02/03 | 真实 OIDC 登录，两账号、两设备会话；错误签名/issuer/audience/过期 token/缺失会话 | 正确账号可用；伪造与过期凭据拒绝；身份不取自请求 owner 字段 |
| T02 | ACC-02, OPS-01 | 以账号 B 请求 A 的 ID、游标、冲突、设备和批次 | 所有入口隔离；响应/错误/日志不泄露 A 的正文和存在性细节 |
| T03 | ACC-03 | 撤销设备会话后重用旧 token、重新注册旧会话、下一轮 push/pull | 下一请求拒绝且旧会话不可重新绑定；新登录策略有明确说明 |
| T04 | SYN-01/03 | 多端并发提交、数据库提交次序反转、分页拉取、重复拉取 | 账号游标不漏已提交操作；apply 与 cursor 同一事务；push 不越过未拉取事件 |
| T05 | SYN-03 | 同 opId 同载荷重复，异载荷重用 opId，依赖未就绪后重试 | 相同请求返回原结果；改载荷拒绝；暂时错误不会永久锁死操作 |
| T06 | SYN-04 | A/B 离线从同 revision 编辑同一正文 | 一方成功、一方明确冲突；双方完整正文可取回，解决动作可追踪 |
| T07 | SYN-05 | 删除后旧离线 put、旧 restore、当前 revision restore | 不静默复活；仅明确且版本正确的恢复成功 |
| T08 | SYN-02/08 | 在本地落盘、发送、服务端提交、收到 ack、写 cursor 各点中断并重启 | 最后确认保存的数据不丢；无重复副作用；状态与真实落盘结果一致 |
| T09 | ACC-02/04 | A 尚有 outbox 时切 B，再切回；退出、刷新和重登 | B 无法读取/发送 A 的数据；退出清理范围准确，不删用户原 PDF |
| T10 | SYN-07 | 两账号×两本地库、相同 local ID、路径/密钥/headers 哨兵、未绑定库 | 稳定 ID 不串库；wire/诊断/冲突无本机路径或秘密；源对象和原文件不变 |
| T11 | LIB-06, SYN-07 | 同路径换 PDF、移动路径同 hash、缺失 hash、旧坐标缺版本证明、富文本笔记 | 不猜版本/不压平富文本；明确 skipped；同一已验证版本身份稳定 |
| T12 | LIB-01, NOTE-02 | 两个独立客户端编辑文库/新笔记并同步，服务端重启后再读 | 双向可见且持久；查询/编辑/冲突按钮真实工作，无预设演示成功 |
| T13 | READ-01/03, NOTE-01 | iPhone/iPad/Android 手机/平板选择文本、划线、缩放、旋转、定位引用 | 坐标和引用在同一 PDF 版本正确；触控可用；屏幕尺寸不遮挡主操作 |
| T14 | NOTE-03, SYN-06 | 编辑后切后台/锁屏/终止进程；离线 24h；跨设备从较早页继续阅读 | 确认保存内容恢复；最近位置不误用最大页；正在阅读不被远端强制跳页 |
| T15 | PDF-01/05/06 | Range/非 Range、跨域限制、重定向、HTML 伪装、404、过期链接、大文件 | 有准确错误和回退；未主动请求不整库下载；临时缓存受限且可清理 |
| T16 | PDF-02/03 | 同账号/异账号、电脑睡眠/离线、NAT 直连失败、传输中撤销、任意路径请求 | 仅授权附件可读；有限等待；撤销中断；中继按政策清理并计量流量 |
| T17 | PDF-04 | 主动上传、重复/中断上传、超配额、删除云副本 | 不隐式上传；私有隔离；删除云副本不删文库记录或电脑原件 |
| T18 | AI-01/02/03 | 电脑关闭，手机自己的模型配置；选段问答/整篇问答、保存笔记 | 外部 API 路线独立；发送范围明确；引用可核对；没有全文不伪称读过 |
| T19 | AI-04/05 | 401/429/超时/断流/取消/费用未知/密钥更换；检查同步和日志 | 不泄露密钥；不伪造流式或消耗数字；失败可恢复且结果不被覆盖 |
| T20 | AI-06, PAR-05 | 长任务发起/取消/重启/重复请求/版本更换 | 状态持久、任务幂等；结果只绑定正确版本；不要求移动后台常驻 |
| T21 | PAR-01..06 | 按完整清单逐项与隔离桌面对照 | 功能存在、输出可用；远程依赖与不可用原因明示，无死按钮 |
| T22 | OPS-02 | 一致性备份、全新实例恢复、密钥/配置恢复、损坏和高版本备份 | 条数/hash/关系/冲突完整；错误备份拒绝且原实例不变；记录实际 RPO/RTO |
| T23 | OPS-03 | 旧版数据升级、中途失败、重启恢复、允许的回滚 | 文件和业务数据完整；迁移可重入；不支持回滚时明确阻止而非尝试破坏 |
| T24 | OPS-04 | 选定基准设备、文库规模、并发量、文件集与网络条件，持续负载和容量测试 | 公布实测 P50/P95/P99、错误率、内存、磁盘/带宽和恢复时间，满足发布前确定的预算 |
| T25 | OPS-05 | 字体放大、VoiceOver/TalkBack、键盘、深浅色、减少动画、离线提示 | 主要工作流可完成；文本/操作不截断；焦点和读屏顺序合理 |
| T26 | OPS-06 | 当前 SHA 全套 CI、代码和安全审查、签名包、安装升级、外网真实客户端 | 无未处置 P1/P2；实机与生产记录齐全；不将旧版本/模拟器结果当当前结果 |
| T27 | 既有功能 | WebDAV、共享库私人设置、notes/RAG 边界、radar 队列和现有 tests | 新功能关闭时旧行为不变；用户原库/profile/运行实例未被测试操作修改 |

## 阶段门槛

- **M1：** T01–T12、T27 的适用范围必须有证据。纯投影通过不等于旧 Reader 双向接入通过；浏览器 IndexedDB 通过不等于原生持久层通过。
- **M2：** T13–T15、T18–T19、T25 的核心流程须四类真实设备验证，M1 回归保持通过。
- **M3/M4：** T16–T17、T20–T21 与新增迁移/回写回归通过。
- **M5：** 所有适用项通过，T22–T26 有可复现操作记录；基线已知启动 SQLite 路径 P2 单列处置，不能由新同步功能抵消。

## 性能与恢复预算

在实机阶段选定最低支持系统、低端/主流设备、文库规模、PDF 页数/大小、网络条件、目标并发、磁盘/带宽预算和 RPO/RTO；这些是待基准验证的发布条件，不是本方案已经达成的数字。若基准不能满足，调整实现或明确支持范围后重新验证，不擅自降低数据完整性、安全和业务正确性的门槛。
