仅发送文字、公式与表格内容；图片只保留文字与题注。可能有 OCR 错误，超限拒绝，不声称阅读全文。更换或清理解析包会使旧上下文失效。

按验收门槛推进

同步会话与模板 · 显式保存

  1. 01核对原文保存实际 PDF／解析文字、问题、公开模型引用和真实终态。
  2. 02本地先落盘完整快照、版本与冲突在同一事务复核，随后进入同步队列。
  3. 03另一设备重开读取共同原文；模板仅填入输入框，重开不会自动请求模型。
  4. 04明确继续提问每次发送共同原文与此前完成的问答，结果不明不当成完成。

每账号至多 50 个会话、100 个模板；每会话至多 24 轮／1 MiB。密钥和模型配置保留在各设备；旧客户端无法覆盖不支持的内容。最新跨端浏览器脚本已准备，实际服务链尚未通过本轮验收。

结构笔记 · 保留原始结构

  1. 01编辑完整结构公式、表格、任务和受校验图片；Markdown 保留原格式。
  2. 02保存与同步保留 AST、元数据和资源摘要，未知节点或超限整条拒绝。
  3. 03导出 v2 文件桌面已保存笔记、移动文库或阅读汇总；跳过原因保留。
  4. 04目标账号重绑新建目标 ID，包内引用重新连接；未知引用明确未解析。

单条笔记 1 MiB；图片仅 PNG/JPEG/WebP，有字节数、尺寸与 SHA-256。导出不能替代完整备份，历史坐标仍未验证。

电脑远程任务 · 可恢复执行

  1. 01选择与确认指定同账号电脑、公开配置、PDF 版本，确认外部发送与可能费用。
  2. 02持久保存请求移动端保存原请求；服务端按账号排队，租约和 fence 约束执行。
  3. 03电脑固定读取读取选定映射，复验文件并持久保存执行阶段后才调用外部服务。
  4. 04核验与恢复产物绑定原版本；已知批次恢复，不明提交保留且不重发。

远程能力默认关闭，电脑每次启动须明确开启。换绑先核验本机执行日志；无旧记录不能重发付费任务。服务端配额、产物和本机记录可查看；真实付费服务尚未验收。
