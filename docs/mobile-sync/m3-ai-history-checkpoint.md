# M3 本机问答记录与问题模板检查点 · 2026-10-28

已接通按账号隔离的独立问答记录与问题模板：明确保存实际输入、问题、模型公开引用和执行终态，刷新重新登录后可重开。AI-04 当前只完成本机这一部分；跨设备会话、多轮恢复和 M3 整体验收仍未完成。四类实机继续按用户要求暂缓。

## 实现

- 严格版本化 DTO，拒绝未知字段、凭据配置、等长选段错配和超限数据；来源摘要、页码引用由保存的输入重新派生。实际请求控制器捕获原问题、公开 provider、精确 context identity 和起止时间，覆盖完成、失败、不完整、取消及被替代请求。
- Web 独立 IndexedDB、原生账号 SQLite 适配器；每账号 50 条问答、100 个模板、共 16 MiB，单记录 1 MiB、单模板 16 KiB。原子写删、摘要核验、模板 CAS、持久代次和排队写入保护；删除/清空后旧保存不能复活。坏控制记录可通过明确清理恢复，存储失败不静默降级。
- 查看记录不请求模型；复用模板和历史问题只填输入框，已有不同草稿需确认替换。查看原文、PDF 版本/解析摘要、真实终态和用量；费用未知。问答/模板只存本机，密钥不进入 DTO；另存的文献笔记照常同步。
- 账号切换撤下旧视图，晚回包、旧保存与旧页码事件不能跨账号或版本生效；账号本机副本清理后按账号 epoch 重置已打开的归档 UI。
- 浏览器发现桌面内联 AI 转手机弹层后，Escape 关闭可能留焦在隐藏分支。现在在原 opener 不可用时返回最近可见控件，浏览器退焦至 body 的情况也覆盖；保留嵌套 modal 和 inline 编辑器保焦。两项修复前失败回归与最终证据均保留。

使用方法与数据边界见 [本机问答记录与问题模板](ai-history.md)。

## 保留的失败与环境处理

- 初始移动完整测试 723/724：既有长作者空白有界解析用例超时；当时根项目与移动测试并发。该用例独立运行通过，后续完整有界并发 2 的 730/730、最终 732/732 都通过。原失败日志保留，不把初次运行计为全绿。
- 早期浏览器脚本曾忽略刷新确认、重复使用夹具标题、过早读取异步页码、刷新后未重新登录、未选择提问任务、第二设备未先打开本机 PDF，以及缩窄时仍留在解析弹层；均核对实际状态后修正验收脚本。响应式关闭后的隐藏焦点是实际产品问题，已修并复验。
- 累计合成测试账号达到 100 个活跃设备会话，注册返回 409；只读事务确认 116 条保留会话/100 条活跃会话。沿用环境中已有的另一合成账号完成最终验收，未删除历史、撤销会话、提高限额或更改 realm/client。
- 共享盘的 Vite 输出清理出现 `ENOTEMPTY`，按准确 PID/启动时间/可执行路径停止本轮 preview，核对路径后保留未完整清理的生成目录，再从空目录正常构建。最终 preview 首次探测赶在监听前失败；确认 HTTP 200 后完成最终一轮，失败记录保留。

## 剩余边界

问答和模板没有云端副本、迁移/导入导出、多轮恢复或桌面会话对齐。SQLite 适配器测试不能替代 iOS/Android 生命周期、真实系统持久化、签名安装与升级。离线检查仅覆盖已加载应用，未验收离线冷启动。合成解析包及合成模型不能证明真实 Electron 导出来源链、外部模型质量/费用/CORS 或真实 Zotero 账号增量。

此前本机桌面 API 4312 虽已获用户授权，启动仍被自动审批拒绝，仅有 `blocked by policy`、没有具体理由；本轮没有重试或替代执行。真实桌面解析→导出→移动导入继续保留为阻塞。远程解析/索引、完整富文本、外部库真实账号/增量、跨设备会话、实机与生产门槛仍待后续。本轮保存本地检查点，不推送、合并、安装或部署；本地 head 不继承 PR #35 旧 head 的 CI/审查回执。
