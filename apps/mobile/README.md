# PaperQuay 移动端

独立 React + Vite 客户端，使用同仓 `packages/sync-core`，并提供 Capacitor iOS/Android 工程。M2 接入系统浏览器登录、安全存储、SQLite 与 PDF 私有缓存；原生接入说明见 [NATIVE.md](NATIVE.md)。当前自动化与浏览器证据不代表原生生命周期或四类设备验收完成。

## 本地运行

需要 Node.js 22.18+（或更新的受支持 LTS）和 npm。复制 `.env.example` 到 `.env.local`，填写公开的同步服务地址、OIDC issuer 和客户端 ID；不要放入密码、访问令牌、refresh token 或模型 key。

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

默认开发地址为 `http://127.0.0.1:4317`，回调为 `/auth/callback`，退出回调为 `/`。第二个隔离客户端可用 `npm run dev -- --port 4318`；需在身份服务与同步服务分别加入该 origin 的回调及 CORS 白名单。生产部署使用 HTTPS，只有精确的 loopback 主机允许 HTTP。静态托管必须将 `/auth/callback` 回退到 `index.html`。

OIDC 客户端应为 public client，Authorization Code + PKCE S256，不配置 client secret；业务 API 必须验证 issuer/audience/签名/有效期/client/sid，并将 audience 映射到访问令牌。参考本仓移动同步服务的部署说明。退出会尝试身份提供方退出；连接失败会显示错误，本机认证状态已经清除。

Windows 上如果继承的 PATH 长到 npm 子进程无法找到 node/tsc，可以只对当前命令设置一个包含 Node、Windows/System32 和 Git 的较短 PATH；不要修改系统级 PATH。建议从映射盘符运行，避免 cmd 的 UNC 工作目录限制。

## 已实现的操作

- OIDC 登录、当前登录会话注册、查看和撤销设备会话、退出账号。
- 题录新建/编辑、标题/作者/关键词/DOI/年份/来源/摘要搜索、删除状态查看；收藏、阅读状态、标签、合集和阅读队列通过能力协商跨端同步。
- Markdown 笔记关联文献、自动保存与安全预览；只有本地事务完成后才显示已保存，网络同步另有状态。
- 本机 PDF / 公开 PDF 链接、SHA-256 版本核验、目录/搜索/缩放/旋转、分页/连续阅读、文字高亮/下划线/区域批注与按设备阅读位置。
- 账号隔离的 PDF 临时缓存、主动离线保留和清理；阅读器资源随按需模块打包，已打开应用断网后可重新打开缓存并渲染新页。
- 直接连接本设备配置的模型服务，明确选择选段/本页/全文可提取文字；真实 SSE、取消、可核查页码引用和结果保存为笔记。详见 [AI 接口与边界](src/ai/README.md)。
- 当前版本与本机最新保存版本对比、原冲突提交查看、保留任一版本、笔记正文手动合并、针对墓碑的显式恢复。
- 按服务地址与服务端账号 UUID 隔离 IndexedDB。本地编辑、outbox、服务端镜像、游标和待确认冲突解决请求原子提交。
- 网络失败/丢失 ack 后以原 opId 重试；发送期间的新编辑保留为 overlay；账号切换取消旧请求并忽略迟到回包。

依赖尚未同步的操作和冲突解决请求会暂缓，让其他排队操作先发送；本轮有成功写入后才重试依赖，操作的 opId 和载荷保持不变。普通可重试错误和结果不确定的请求等待下一次同步触发，持续缺少的依赖会保留本机数据并显示未完成状态。单轮达到处理上限后仍拉取远端，剩余请求保留待同步状态；失败请求持久化移到队尾，下一轮或重启后继续推进。离线显式恢复后继续编辑，尚未发送的操作仍保留恢复意图。

冲突决策只消费页面实际展示、纳入选择的本机 overlay ID；该 ID 和解决请求一起落盘，决定之后保存的新编辑不会被误消费。若另一设备解决了冲突，客户端补拉最新变更后才解除本地阻塞；未经该设备审阅的本机后续编辑保留原冲突的版本基线，由服务端再次比较版本，发生并发时继续人工处理。

未保存的编辑在页内导航和离开页面时会提示；编辑期间的新远端版本不会替换草稿。若服务端版本已更新，需比较后明确保存。笔记停止输入 600ms 后自动保存，批注评论为 450ms；保存中的新输入保留为新草稿。以实际保存状态为准，不能把输入框中的文字当作已经持久化。

切换记录或离开编辑器后，旧记录的保存、删除和恢复仍可完成持久化，但迟到回调不会清除新草稿、触发返回或改变新编辑器的错误/保存状态。

正在编辑的合并草稿对应的冲突被其他设备关闭时，当前冲突快照、标题、正文和离开提示仍保留。页面会标明冲突已关闭并停用原解决按钮；可选择“另存为新笔记”，在本机保存完成后打开新笔记。保存失败会保留草稿，切换到其他冲突仍需确认放弃未保存文字。

Web 令牌与模型密钥仅留在内存。OAuth 跳转所需的短期 state/PKCE 使用独立 sessionStorage，设备显示名称也以独立字段跨登录跳转保留；公开服务配置可存 localStorage，内容只存 IndexedDB。Web 刷新后需要重新登录，重登后恢复此前确认保存的改动；未提供离线冷启动 PWA。原生端使用系统安全存储、SQLite 和私有目录缓存，只可从此前经服务端确认的身份绑定恢复已有离线快照，重新联网后先验证会话。

“撤销设备会话”“退出登录”“清除此账号的本机副本”是独立操作。清理账号本机副本会删除未同步改动及该账号全部 PDF 缓存（包括主动离线保留），不删除服务器数据或桌面原 PDF；阅读器的“清理临时缓存”保留主动离线文件。数据库不可用/格式错误会明确失败，不降级为假装保存成功的内存缓存。

撤销当前会话后会继续执行身份提供方退出；被其他设备撤销的会话显示“退出旧会话”入口。退出旧 SSO 会话后再次登录才能获取新的 `sid`，避免授权页面复用已被撤销的会话。业务撤销和身份提供方退出不是同一个事务；退出网络失败会明确显示。

## 验证边界

`npm test` 覆盖 IndexedDB 重启与并发事务、账号隔离、账号切换迟到回包、提交后丢 ack、请求途中编辑、依赖队列推进与重试上限、远端冲突解决后的后续编辑、离线恢复后编辑、冲突解决请求恢复、编辑版本检查、API 响应验证和令牌存储边界。账号保留字节额度不足时明确提示本机内容仍保留；push 与 resolve 的可重试拒绝均保留原请求及后续编辑，跨重启不空转、不误报完成，额度恢复后精确重试。实际冲突组件的重渲染测试还覆盖远端关闭时保留合并草稿、切换确认、已关闭冲突的提交拦截与另存成功/失败。实际 App 与编辑器组合还验证重复选择同一记录后继续输入的未保存保护，以及不同记录、类型和新建草稿的切换确认。这些故障注入测试使用假 IndexedDB/API；真实 PostgreSQL/OIDC、两个浏览器 origin 和响应式视觉验收记录在 `docs/mobile-sync` 的验收材料中。

M2 的测试、生产预览交互、PDF 资源与模型请求证据见 [M2 验证记录](../../docs/mobile-sync/qa/m2.md)。单 PDF 上限 64 MiB/2000 页，页面按需窗口渲染，公开源须经用户确认完整读取后才能核对版本。首次阅读模块还包含约 5.16 MB（gzip 约 2.54 MB）的离线 worker/字体/CMap/WASM 资源；此成本随首次进入阅读器发生，不随整个文库预取 PDF。

此阶段不包含电脑文件中继、私有云上传、旧桌面 Reader 双向接入、完整富文本迁移、持久 AI 会话、远程解析、后台常驻同步或签名发布。四类真实设备、系统终止恢复与真实提供商网络行为仍待验收。
